# 接话与抖机灵样板 reaction-rich-03

沿用用户认可的多场景、多神态方向，新生成四词各一张静态画面：

- **我就看看**：窗帘后偷看，装作不参与却藏不住好奇。文件 `watch-curtain.png`。
- **真的假的**：放大镜夸大一只眼，认真查证式质疑。文件 `really-magnifier.png`。
- **让我想想**：表面认真思考，脑内仓鼠却在睡觉。文件 `thinking-idle-wheel.png`。
- **溜了**：慢吞吞的蜗牛穿轮滑鞋机灵退场。文件 `leaving-skates.png`。

使用内置 image_gen 独立生成，未使用第三方参考图作为输入；完整提示及SHA在manifest.json。root已逐张视检。当前不含中文字幕、不是GIF、未入APK；正式发布前仍需每词四风格及真实关键姿势。不得以PNG数量代替正式GIF数量，归档144张GIF统计不变。
