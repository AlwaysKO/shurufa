## 发布边界

- 当前目录仍是归档，**不直接对外开放**。批准成品登记到 `assets/expression/manifest.source.json`，由 `cd server && npm run expression:generate` 校验并发布到 `.runtime/expression-assets` 与 Android subset。
- 接口只读取正式生成的 catalog；review-only、索引内工程路径及任何参考图不能对外暴露。本次批准记录在各索引的 publicationApproval 字段，原始生成报告的 review-only 状态作为历史证据保留，不伪造追溯验收。
- 未来推荐成品统一归档到本目录；新增批次仍需审核、更新正式源清单后再运行发布生成链，batch命令不会自动批准或发布草稿。
- 外部参考图仅在具备相应接口/素材使用权限后保存，须与成品隔离且不能进入发布清单。本次未调用搜狗搜图或下载搜狗图片。
- 创作继续遵守 `assets/expression/CREATION-POLICY.md`；借鉴一般风格/情绪/节奏，不复制角色、标识、原图构图或仅做微改。

## 缓存目标

查询命中可用本地缓存，7天内不请求推荐接口；过期先展示旧缓存再刷新。成功取得的新结果才更新获取时间，不因每次读取滑动延长有效期。失败保留旧缓存，不标作新鲜。部分原件缺失仅修复缺件，不反复拉取新鲜的推荐索引。Android查询索引7天TTL与64MB原件缓存沿用既有实现，补充了6天内重复读取零请求、8天过期刷新失败保留原件和旧获取时间的网络断言。
