## 一、以后日常怎么用

### 1. 在自己的 Windows 电脑提取

1. 登录电脑微信，打开收藏表情面板。
2. 双击桌面的 **“微信收藏导出”** 快捷方式；本机已配置当前微信账号，无需后台地址或配对。
3. 工具开始提取，等待显示成功、失败数量；完成后自动打开图片文件夹。
4. 检查导出的 GIF 能播放。异常文件不要强行改后缀、修复或转静态后混入正常图片。

此方式无需填写线上后台地址、无需配对码，也不用工具常驻；提取后可以关闭工具。提取时仍可能需要网络下载微信原图，并非完全离线操作。不能在服务器运行该工具读取家中电脑的微信。

**现有文件可以复用：** 本机早期导出目录为 `C:\Users\ES-11013\Downloads\shurufa-wechat-2026-09-29`。正常 GIF/静态图片可作为批量上传输入，“待检查”文件不要全选上传。该目录是历史快照，不代表当前收藏数量或最新校验结果；无需为了新入口重复提取已有完好原图。

### 2. 打开线上后台，批量选择图片

新版入口：后台左侧 **个人资产 → 表情素材库**，路径 `/sticker-materials`。旧“关键词推荐图”页内的“表情素材库”标签也保留。线上发布本次版本后可访问 `https://my.dog8ball.com/sticker-materials`。

本次已实现的批量操作（本地可验证，线上需先发布）：

1. 点击“选择图片批量上传”，在本机文件选择器中多选导出的正常原图。
2. 选择文件后自动开始，无需逐张填写关键词；每批最多 1000 张，每张不超过 10 MiB。
3. 页面先计算原文件 SHA256，与当前线上图库比对，只上传缺失图片。
4. 等待明细，核对“后台已有、新增成功、本批重复、失败”；点击“重试失败或未完成项”只重试这些项。
5. 上传期间保持网页打开。关闭网页不应被描述为仍会后台持续上传；已成功入库的图片保留。

“在服务器上传”指在浏览器中选择本机图片并上传到线上后台，不用先通过 SSH/SCP 把文件复制到服务器目录。不要上传 ZIP、微信数据库、工具配置或密钥文件。

### 3. 为图片关联关键词

1. 进入素材库默认显示“未分配”，新上传图片排在前面；可切换查看全部或已分配。
2. 在图片卡片的“搜索已有推荐词”输入字，例如 `早`；候选会匹配已有组名及同组说法，显示 `早安`、`早点休息` 等已有组。点击 `早安` 就完成分配，不必再逐个选择同组说法。
3. 卡片按关键词组显示已有关联；同组说法共用图片，配置沿用“关键词推荐图”。一张图还可搜索并选择其他组，已关联组不会重复添加。
4. 点击某个关键词组旁的移除按钮，只移除该组关联，不影响其他组；这个组的所有同组说法将不再通过该组推荐此图。
5. 移除最后一个关联后，图片回到未分配状态，原图仍保留。

找不到候选时，去“关键词推荐图”新增或维护组名和同组说法，再回来刷新。素材库不提供自由建词或说法编辑。候选已被删除时会提示刷新，不会自动重新创建。

未分配图片不参与手机推荐。关键词推荐图库由所有设备共享，不需要选定某一台手机。

## 二、重复图片如何处理

| 情况 | 处理方式 |
| --- | --- |
| 同一原图再次上传，仅文件名不同 | SHA 相同，跳过新增，保留原关键词 |
| 历史同图有多条记录 | 汇总展示关联，不自动合并旧 ID、排序或使用次数 |
| 图片看着相同，但经过压缩、裁剪、转码 | SHA 可能不同，不保证识别为重复 |
| 历史原图全部缺失或不可用 | 报告异常，不假报已有可用，也不擅自替换旧图 |
| 上传一部分后断网 | 已成功的保留；恢复网络后重新选择可再次去重 |

单张图片上限为 10 MiB。保留原始 GIF 字节，不以静态图代替动画。不要因重复选择就批量删除旧素材。

```powershell

```

2026-09-30 实际提取：364 条收藏，361 张有效原图，3 张异常图跳过；这是本次快照，不是永久固定数量。图片 SHA 文件名与内容一致；再次导出复用相同原图，不删除旧文件。工具只做本地导出，不自动上传。

换电脑首次安装：将 `tools/wechat-sticker-import` 完整复制到可信的本地 NTFS 目录，安装 Python 3.12（含 py 启动器），在 Windows PowerShell 5.1 中执行：

```powershell
.\install-export.ps1 -AccountDirectory 'D:\xwechat_files\你的账号目录' -WeixinExe 'D:\微信安装目录\Weixin.exe'
```

账号目录须包含 `db_storage\emoticon\emoticon.db`。独立目录 `%LOCALAPPDATA%\shurufa-wechat-export` 与配对助手分开，不需要服务器参数。重复安装保留 `export-config.json` 和图片；换账号先关闭导出窗口，再修改此配置中的本机路径。不要上传此配置或 venv。

遇到执行策略阻止时，不要用 Bypass 或修改系统策略；使用已信任的本地源码目录。当前仅实测 Windows 微信 4.1.13.65、Python 3.12、Windows PowerShell 5.1；不声称 Mac 或其他微信版本可用。按 Ctrl+C 取消，已完成的原图保留；退出码 2 表示部分图片失败，并非全部失败。
