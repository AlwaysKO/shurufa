## 一、以后日常怎么用

### 1. 在自己的 Windows 电脑提取

1. 登录电脑微信，打开收藏表情面板。
2. 运行交付后的本地独立导出工具，确认微信账号目录和图片保存目录。
3. 点击提取，等待显示成功、失败数量和输出文件夹。
4. 检查导出的 GIF 能播放。异常文件不要强行改后缀、修复或转静态后混入正常图片。

此方式无需填写线上后台地址、无需配对码，也不用工具常驻；提取后可以关闭工具。提取时仍可能需要网络下载微信原图，并非完全离线操作。不能在服务器运行该工具读取家中电脑的微信。

**现有文件可以复用：** 本机早期导出目录为 `C:\Users\ES-11013\Downloads\shurufa-wechat-2026-09-29`。正常 GIF/静态图片可作为批量上传输入，“待检查”文件不要全选上传。该目录是历史快照，不代表当前收藏数量或最新校验结果；无需为了新入口重复提取已有完好原图。

### 2. 打开线上后台，批量选择图片

入口：`https://my.dog8ball.com/stickers` → **表情素材库**。

以下批量入口待实现，上线后按最终按钮名称操作：

1. 点击“批量上传图片”，在本机文件选择器中多选导出的正常原图。
2. 确认选择后开始上传，无需逐张填写关键词。
3. 页面先计算原文件 SHA256，与当前线上图库比对，只上传缺失图片。
4. 等待结果，分别核对“已有跳过、新增成功、失败”；失败项应可单独重试。
5. 上传期间保持网页打开。关闭网页不应被描述为仍会后台持续上传；已成功入库的图片保留。

“在服务器上传”指在浏览器中选择本机图片并上传到线上后台，不用先通过 SSH/SCP 把文件复制到服务器目录。不要上传 ZIP、微信数据库、工具配置或密钥文件。

### 3. 为图片关联关键词

1. 筛选“未分配”，逐张预览图片。
2. 在图片卡片输入关键词，多个词用逗号分隔，例如 `开心,高兴`，点击“添加关联”。
3. 卡片显示该图全部已有关联；以后可继续添加其他词。
4. 点击某个关键词旁的移除按钮，只移除该关联，不影响其他词。
5. 移除最后一个关联后，图片回到未分配状态，原图仍保留。

未分配图片不参与手机推荐。关键词推荐图库由所有设备共享，不需要选定某一台手机。

## 二、重复图片如何处理

| 情况 | 处理方式 |
| --- | --- |
| 同一原图再次上传，仅文件名不同 | SHA 相同，跳过新增，保留原关键词 |
| 历史同图有多条记录 | 汇总展示关联，不自动合并旧 ID、排序或使用次数 |
| 图片看着相同，但经过压缩、裁剪、转码 | SHA 可能不同，不保证识别为重复 |
| 历史原图全部缺失或不可用 | 报告异常，不假报已有可用，也不擅自替换旧图 |
| 上传一部分后断网 | 已成功的保留；恢复网络后重新选择可再次去重 |

单张图片上限为 10 MiB。保留原始 GIF 字节，不以静态图代替动画。不要因重复选择就批量删除旧素材。

## 三、配对助手还用不用

日常采用本手册方式时，**不需要配对**。已有配对方案暂时保留，不要求安装或启动。

只有希望“保持本机助手运行，在网页点击后自动读取并上传收藏”时，才使用 [配对助手说明](../tools/wechat-sticker-import/README.md)。两种方式应复用同一素材库和精确去重规则，不建立两套图库。
