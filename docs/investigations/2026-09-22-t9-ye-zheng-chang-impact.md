# T9 通用词组评分与组合召回影响评估

日期：2026-09-22。结论：**本次试验的词组频率评分与后缀组合方案有可复现退化，不能按“确认无影响”直接应用。** 这不等于所有通用方案必然有同样风险。实验代码全部位于 `/tmp/shurufa-t9-impact-audit`，本文件仅记录调查；没有修改正式 T9 源码、词库、手机或个人库。

## 方法

使用正式 `OfflineT9Candidates.select` 作为基线，当前真实主词库/领域词库/公开词索引，个人数据库设 null。将生产对象复制、改名为 `AuditOfflineT9Candidates`，仅替换原生整句分组的排序/候选增加。两个对象使用相同数据与数组。

方案 A：只对已经通过原生整句门槛的候选，用词库中“文字 + 读音”准确匹配的多字词计算动态规划最大切分分数，单字得分为零，多字词得分为 `字数 × ln(1 + 词频)`。保持同分原序，不修改可信整词、过滤、单音节、锁音路径。

方案 B：在 A 的范围内，保留原生候选的前缀文字/读音，用词典查询剩余数字码补充二字及以上后缀；校验总音节数、整句按键匹配和合法末字补全，再参与评分。没有添加“也正常”词条，也没有坏词黑名单。这个实验不是可交付实现。

## 真实录制数组回放

覆盖仓库全部可用于候选比较的回放：305 条公开语料 + 16 条长句逐键快照，共 321。另有 29 条 full-display 回放仅保存 READING，没有候选文字，不能当作整句排名覆盖。

| 方案 | 列表变化 | 首选变化 | 目标排名改善 | 目标排名退化 |
| --- | ---: | ---: | ---: | ---: |
| A 仅重排 | 0 | 0 | 0 | 0 |
| B 重排 + 后缀召回 | 133 | 97 | 52 | 3 |

统计口径：每个 fixture CASE 计一次；比较 `firstPage` 整个候选列表（该字段并非只含 UI 前 8），首选取索引 0，目标位置按 fixture 标签；目标不在列表时记 1000。长句文件统一观测最终目标“我不再彷徨”，中间码目标通常不应出现，因此另查既有“我不再”前 8 契约。52 个“改善”表示目标出现/位置前移，未对所有其他新候选作语义验收；97 个首选变化不等于 97 个错误。未将逐键快照的正反遍历重复计数，也没有把静态回放说成真实按键/退格交互。

3 个退化为：有点累了（索引 0→2，前面变为“有点累累、 有点磊磊”）；现在用不上（0→8，被“现在用不是”等挤出前 8）；买两瓶水（0→1，变为“买两清水”第一）。新候选还会出现“我不再膀胱”“我们出塑造”等错误搭配。

长句中间态 `96289247` 的“我不再”从前 8 被挤出，违反 `T9LongCompositionTest` 的已有分段前缀可用性要求；因此只统计最终整句首选不够。

## 本次反馈的受控复现

`93943642` 是 `ye=93`、`zheng=94364` 后追加 `2`，既可解释成 `a` 也可补全 `chang=24264`；`939436424264` 是完整 `ye zheng chang`。实验保持当前仅末音节可补全的匹配约束。

对这两个原始反馈编码分别输入坏候选“也正啊”“也正厂”，并各分为原生数组包含/不包含“也正常”两种情况：

- A：原生已有“也正常”时能提升首位；原生没有时无法补出。
- B：两种情况均能补出或提升“也正常”，但上述既有输入退化不能接受。

这些数组是受控输入，**不代表读取了用户手机当前原生候选**。

## 为什么 A 的零变化也不足以证明安全

补充相同代码与合法读音的受控多整句竞争（使用同一真实词库）：A 将“有点累了”排到“有点累累”后，将“现在用不上”排到“现在用不是”后，将“买两瓶水”排到“买两清水”后。对照“我不再彷徨 / 我不在彷徨”保持原序。

词频仅表达局部词常见程度，不能表达前后文搭配是否自然；已有 321 条录制语料未覆盖这些多整句竞争，不能把零差异解释为普遍安全。

## 可明确界定的影响边界

- 可信整词/合法末字补全：沿用 `hasDictionaryWhole`，存在时不启用实验整句分组，因此可在代码结构上保护该路径。
- 单音节、短码、字母输入、锁音：原代码路径保留；本实验未动 `rankNative`。
- 已有原生索引：已有项保留索引；组合新增项使用 null，与本地词一样直接提交。但未做真实提交/UI验收，不能称已验证。
- 分段：分段提交算法未变，候选前缀位置可被新整句挤压，已发生退化。
- 个人优先：排序器逻辑未变，近期明确选择和手工词入口保留；但基础序变化会改变较旧学习记录的先验，因此不能宣称个人行为完全不受影响。未跑真实 DB/Robolectric 个人重开测试。
- 原生整句：这是直接改变的区域，有正反例且无法用已有词频消除反例。
