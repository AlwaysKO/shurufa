# 「我就看看」四风格 GIF 实现计划

**目标：** 用户授权自行选词，制作同词四风格独立试稿；不动旧图、不发布。
**架构：** 复用现有参考角色渲染器，仅扩展固定原创批次；沿用原审计与字体。
**技术栈：** 内置 imagegen、TypeScript/sharp、Vitest。

设计：写实灰猫侧眼、极简线条长颈鸟偷瞄、黏土海豹假装淡定、原创中国成年男性挑眉。相比全动物或全人物，混合风格满足每词四种风格，减少偏插画人物；人物只做一张真实感演出。均眼神先行、微小动作、关键停顿、渐进回正。

1. 生成每款4×3十二姿势母版，保存提示词、源图及SHA，检查连续性。
2. 先新增固定四项测试，确认因清单缺失失败；最小新增清单与look01 CLI，不改变来源/发布门禁。
3. 实际渲染240×240、20帧、4000ms、低于250KB与首帧WebP；沿用原审计，不放宽阈值。
4. 检查解码抽帧、哈希、动态预览、相关测试及构建。静态与动态均标记待用户审核；问题稿保留rejected。

依据：CREATION-POLICY.md 全部修订、serious-v2生产记录及参考/原创试稿计划。4秒是后续方向，不冒充已认可成品。
