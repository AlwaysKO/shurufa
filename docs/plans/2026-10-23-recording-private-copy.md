# 通话结束后先保存私有录音副本

**目标：** 电话、微信通话录音在系统发布且稳定后尽快复制到输入法私有队列，再独立上传；原件在上传期间删除不能损坏任务。

**现状与选择：** 导入器已经流式复制、同步落盘并发布持久清单，上传只读私有文件；不能再复制一套缓存。缺口是微信即时调度要求Wi-Fi、普通电话没有独立结束触发、离线稳定复查未持续。采用复用现有队列并提前触发导入，不直接上传原URI，也不在文件尚未封装时盲目复制。

**实现：** 既有微信结束与媒体变更触发器去除网络前置；补普通电话结束广播（复用READ_PHONE_STATE，不读号码、不启动麦克风），两次一致观察且近期明确结束时使用2秒稳定期，其余沿30秒。本地复查有界、输入/游戏仍避让，用户后续明确录音不等Wi-Fi，上传允许有效Wi-Fi或移动网络，图片网络规则不改。复制后的私有待传不因原件删除或超过发现七天窗口丢失；同次自录去重接受已验证私有系统副本/有效保存回执。

**验证步骤：**
1. 先补失败测试：离线发现后的复查、电话结束2秒稳定、广播重复/撤权、复制后删除原件与重启/失败重试、过期已入队继续可传、副本去重。
2. 最小修改导入器、结束/媒体事件和运行调度；保留大小/前后状态校验、清单原子提交、只清私有文件。
3. 录音相关回归、独立审查、构建原签名非testOnly APK并核对交付摘要。

**范围：** 当前分支，保留现有定位/GIF/安装引导改动，不提交推送/部署/连接或安装手机。不承诺系统未发布、未授权、应用被强停或文件在复制前已删除时仍能恢复；不新增高频常驻轮询或永久唤醒锁。Mac交付到本机apk目录。

普通电话结束采用系统受保护的 PHONE_STATE 广播，复用已有 READ_PHONE_STATE 权限；官方后台广播例外说明：https://developer.android.com/develop/background-work/background-tasks/broadcasts/broadcast-exceptions 。没有读取权限或厂商不交付事件时继续依赖音频变更和周期兜底，不承诺瞬时发现。
