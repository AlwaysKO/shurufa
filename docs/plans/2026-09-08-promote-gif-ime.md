# 将已实机验证的 GIF 服务整合为正常入口

用户已确认实验组件可发送 GIF，并要求直接修好正常输入法。将相同组件字符串提升到公共源集，避免当前已选择该组件的手机发生额外切换；DebugGifImeService 类名暂作为内部兼容标识保留，不对用户显示。系统仅注册这一正常雨燕服务，移除旧注册和 debug 重复入口；原 ImeService 作为实现基类保留。公共 InputMethodUtil 同步使用实际服务类，修正设置页识别。应用 ID/签名/数据/发送链路均不改。

测试先红：公共源集/单入口/设置识别结构测试及 Robolectric 当前组件识别回归。然后最小实现；检查 debug/release 合并清单及实际 APK、覆盖安装、不卸载或清数据。手机原已选择实验组件则保持原选择与正常标签；其他旧组件用户升级后可能需在系统选择器重新选择一次正常雨燕，不能声称系统组件改名可无感迁移所有旧版本。第三方微信更新仍需复测。

验证结果：4 项结构测试及 2 项设置识别 Robolectric 通过；debug 构建与 release Kotlin 编译通过。debug/release 合并清单均仅一个正常入口；SDK 和 app 两阶段 release R8 mapping 均保留完整服务名。完整 release assemble 因离线缺 lint-gradle:31.7.2 未完成，单独 app R8 虽结束仍有 Launcher/CrashHandler 缺类警告，不能称 release 运行验证通过，不在本任务顺手改整个发布构建。

已 adb install -r 覆盖安装正常入口的 debug 包（显示名“妙言输入法”），手机此前选旧雨燕服务，已启用并切换到验证过的兼容组件；imei list 核对只剩一个本应用入口。没有清数据或自动发消息。本轮未重复替用户验证动画，发送实现与其已确认成功的实验版相同。
