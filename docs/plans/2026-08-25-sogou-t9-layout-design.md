# 搜狗式中文九宫格布局设计

## 目标

将妙言输入法默认中文九宫格改为用户熟悉的搜狗式布局，使 923×2048 参考设备上的按键尺寸、间距和键位尽量贴近参考截图。英文全键、手写、笔画、纯数字等其他键盘不受影响。

## 布局规格

- 中文九宫格按键区默认高度比例由 `0.300` 调整为约 `0.278`，目标高度约 558px。
- 五列宽度采用搜狗式比例：左功能列约 17%，中间三列各约 21.67%，右功能列约 17%。
- 默认水平边距比例由 10‰ 调整为约 7‰，默认垂直边距比例由 20‰ 调整为约 12‰。
- 左侧标点栏保持三行贯通；右侧依次为删除、重输、数字 `0`。
- 底栏依次为：`符`、`123`、语音/空格、`中/英`、回车。
- 底栏中央键短按为空格，长按启动现有系统语音识别，并继续支持左右滑动移动光标。
- 回车键根据编辑器动作继续执行换行、发送、搜索、完成等既有行为；普通状态显示“换行”。

## 候选栏

候选字和候选区域随默认候选字号一起缩小，目标为当前视觉尺寸的约 82%。候选数据、排序、点击和展开逻辑不变。

## 兼容与迁移

新安装直接采用新默认值。覆盖安装时执行一次布局迁移，使已有设备无需清除应用数据即可看到新布局。迁移仅处理本次涉及的键盘高度、候选字号和按键边距，不改变输入模式、主题及其他个人设置。

## 交互实现

语音/空格键仍使用空格键码处理短按。按键增加明确的长按语音语义，长按计时到达后直接转发现有 `startVoiceInput()`，同时阻止抬手再次输入空格。其他按键继续使用原有长按符号或菜单逻辑。

## 验证

- 单元测试验证中文九宫格五列比例、右侧 `0` 键和底栏键位。
- 单元测试验证语音/空格键的短按键码与长按语义。
- 单元测试验证一次性迁移及重复执行安全性。
- 构建离线 Debug APK，确认 Kotlin 编译与 Android 资源打包通过。
- 在 923×2048 或等比例设备截图复核按键高度、宽度、间距及候选字号。
