# 真机相关任务延后执行说明

## 背景

当前环境没有可连接的 Android 测试手机，无法采集微信、QQ、抖音的真实无障碍节点夹具。原计划明确禁止根据臆测资源 ID 编写应用解析规则，因此三应用适配和真机验收不能在现阶段完成。

## 调整后的执行顺序

1. 先建立 Android 无关的适配器契约、解析结果模型和安全注册表。没有真实适配器时注册表不返回解析器，页面快照被保守跳过，不产生错误归属消息。
2. 基于该契约继续实现协调器、本地原子去重入队、上传器唤醒、媒体截图与裁剪、通知增量解析及可自动验证的验收项。
3. 将微信、QQ、抖音真实夹具采集、应用专属解析规则、重复滚动、无感行为和性能真机验收统一放到设备可用后执行。

## 安全边界

- 不创建伪造夹具，不猜测资源 ID，不宣称任何应用版本已支持。
- 未注册适配器、会话身份不明确或置信度不足时一律返回 `Skip`。
- 后续通用链路使用 fake adapter 做单元测试，只证明协调、去重和上传行为，不替代真实应用回归测试。
- 最终完成定义保持不变；真机相关项目未通过前，整体计划不得标记完成。
