# 后台导航与设备目录实现计划

> **For Claude：** 必需子技能：使用 superpowers:executing-plans 来逐任务实现此计划。

**目标：** 将后台菜单整理为可折叠二级分组，并以服务端搜索分页的用户目录替换无法扩展的手机下拉框。

**架构：** Dashboard 新增无需当前用户身份的分页 `/users` 目录接口，原 `/devices` 改为只返回当前用户设备；Vue 根布局负责用户目录弹窗、搜索分页和折叠菜单。

**技术栈：** Express、PostgreSQL、Vitest、Vue 3、TypeScript。
