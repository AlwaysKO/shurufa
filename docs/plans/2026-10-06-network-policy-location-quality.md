# 分项省电策略与定位质量 Implementation Plan

**Goal:** 按用户确认的A–H分项策略实现采集/上传网络分离，并修复高度展示误导、解释速度可信度，保留真实数据和已有授权。

**Architecture:** 普通数据、位置、聊天文字分别按独立时间门槛选择持久队列；图片按来源决定网络与输入约束，沿用有界并发和带宽。录音发现与Wi-Fi上传分离；低优先级词库/配置合并一个刷新批次。定位采样、上报、质量校验分开。

**Tech Stack:** Android/Kotlin/SQLite/Room/JobScheduler、Vue/TypeScript。

## 已确认需求

- A普通数据Wi-Fi1分钟/流量15分钟；B使用记录本地30秒、上传Wi-Fi5分钟/流量15分钟。
- C聊天文字仅有变化时上传，流量5分钟，不被普通15分钟门槛阻塞。
- D导航图可在流量空闲上传；聊天图仅Wi-Fi，取消等待输入空闲的上传门槛，保留后台限速/单并发/游戏保护。截图及编码准备仍避让输入；不承诺所有机型零影响。
- E录音离线发现登记，仅有效Wi-Fi上传、切网中止保留任务，系统原件保留。
- F位置报告两网5分钟不变；均衡移动采样60秒、静止5分钟，疑似移动短时30秒确认。
- G词库/配置/版本统一刷新Wi-Fi30分钟/流量2小时，手动即时。H事件与网络恢复唤醒，空队列30分钟兜底。
- 高度/速度先调查真实采集语义，不伪造海拔、不用5分钟两点均速冒充瞬时速度、不通过放宽可信门槛减少未知。

## 执行及验证

1. 用时间、真实持久队列及MockWebServer红回归覆盖A–D；修改CollectorSyncCadence、DataCollector、EventDelivery、LocalInputStore、ImageUploadRuntime/Schedule、NavigationSync、AppUsageTracker。
2. 录音模块独立覆盖离线发现、Wi-Fi授权/绑定、切网中止及网络恢复唤醒；root统一执行Android红绿。
3. 资源刷新模块移除独立循环并复用Expression Job驱动；用虚拟时钟、Job调度验证30min/2h、手动、离线、网络切换。
4. 定位模块覆盖移动60秒/确认30秒、权限事件/30分钟兜底、高度有限值/垂直精度与后台诚实展示；保留位置不变不上报、原速度诊断。
5. 统一相关Android回归、client位置测试/构建、server兼容测试（若有变更）。独立审查后完整assemble原签名非testOnly包，Mac本机apk交付，授权范围内覆盖安装真机验证。

## 边界

当前分支已有前几轮未提交改动，完整保留。不开分支/worktree、不自动提交或部署后台；涉及后台展示变化区分本地实现与线上可见状态。不变更录音权限范围/删除系统录音，不把测试通过等同于实测续航提升。

## 审查修正与质量口径

- 上传在SQL选取前按类别过滤；同重试优先级下位置、文字及普通报告优先于图片，避免慢图耗尽单批预算。媒体依赖和失败退避仍保留。
- Expression下载任务迁移到5175332，释放旧ID后补排已开启的Usage；取消Usage先核所属组件，避免升级丢失兜底任务。
- 断网保留已有USB本地同步：仅loopback目标且物理USB与健康检查通过；不借USB放行公网。离线主循环30分钟兜底，本地词库另存30分钟资格，手动即时，不占线上刷新资格。
- 新位置只有系统提供有限的高度与0–20米垂直估计误差时才保留高度。依旧是WGS84椭球高；负数不自动判错、不转换为海拔/楼层。协议保持原version1字段，避免已部署后台拒绝整条位置。
- 速度可信门槛不放宽；后台区分缺少速度、缺少速度精度、位置精度不足和速度精度不足。历史数据不改写。Android官方语义： https://developer.android.com/reference/android/location/Location#getAltitude() 与 getSpeedAccuracyMetersPerSecond()。
