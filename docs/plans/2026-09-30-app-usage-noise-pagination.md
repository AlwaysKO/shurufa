# 应用使用降噪与局部分页

**目标：** 桌面与不超过 3000 毫秒的使用段不上报；后台底部明细翻页不重建上方统计及时间轴。

**方案：** 保留所有前台事件参与状态机，结束段落后按系统 HOME 应用与原始时长过滤。旧待传批次沿用同一过滤规则，移除不再需要的待传任务，不伪造上传确认，不删除服务器历史。断档继续保留。前端独立管理分页加载、错误及请求版本，仅更新列表字段。

**步骤与验证：**

1. Android 新增报告规则与桌面查询测试，以及旧队列过滤回归；先见红，再在 `AppUsageTracker.kt` 和 `UsageStore.kt` 接入，添加 HOME 可见性声明。运行 `:yuyansdk:testOfflineDebugUnitTest --tests '*data.usage.*'`。
2. 在 `client/tests/app-usage.test.ts` 补分页加载保留数据、局部错误、切换筛选/设备过期响应测试；先见红，再修复 `client/src/views/AppUsage.vue`。运行客户端测试和构建，并以浏览器验证 DOM 与滚动位置。
3. 只读代码审查、更新验收记录，打包并校验原签名 APK。当前分支原地修改，保护其他会话改动，不提交、不部署、不安装。

**边界：** 新上报规则升级手机后生效；服务器历史数据保留。不更改截图 Wi-Fi 与熄屏上传约束。无 SQL 或数据库结构变更。
