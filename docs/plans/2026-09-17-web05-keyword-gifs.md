# web05 喜感关键词 GIF 实现计划

目标：沿用用户已批准制作流程，补后台空组「当然、谢谢夸奖、好家伙」各四风格。依据最新反馈不改旧图，强化反差、俏皮表情与喜感。

设计：不用统一礼貌微笑，也不只改成圆脸萌宠；采用自信嘚瑟、藏不住得意、夸张惊讶三种不同表演。12项详细设计见批次jobs.json。保持固定脚底与身份，但允许有意义的小幅头姿、眉眼和肢体表演，不用僵硬全身冻结限制神态。选择最小固定批次追加，避免重构既有渲染器。

1. 已完整读项目规则与用户新反馈，浏览器实测可用，真实后台三组均空且没有共用别名。
2. 先追加web05固定清单/来源门禁测试，运行见失败；仅增加web05配置和独立脚本，复用web04已验证门禁，不改旧批次。
3. 网页逐张独立生成12格母图；下载原文件、解码、来源/SHA归档、精确删除并核实后下一张。表演或技术失败则保留并重生成，不调阈值掩盖。
4. 统一缩放、显式脚底对齐，累积framing渲染。真实12姿势→20帧4秒，原审计不变。
5. 导入并逐张后台播放、删除按钮、推荐下载解码/SHA、隔离用户删除重导防复活验证。
6. 只读审查、构建定向测试、来源和审美记录；默认入库非用户实际观看认可。Git只最终GIF及必要代码/文本，不提交母图，不动无字库和其他会话。
