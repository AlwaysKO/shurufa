## 数据取得与语义

手机连接后先核对设备和搜狗版本，再检查应用提供的词库导出/迁移入口及可读取的导出目录；优先使用应用自己的导出能力。不得通过卸载、清数据、解锁刷机等方式取得词库。普通 ADB 能否读取目标数据必须实测，不能以已连接 USB 推断私有数据可读。

只解析与本次个人词库迁移相关的文件。词库可能包含自造词、选词统计或词频，但不等于完整历史输入日志。按实际文件证明字段含义：

- 有词条、无使用统计：保存为外部导入词，使用次数和最近使用时间记为未知。
- 有已验证的使用统计：原值及其含义单独保存，不直接转换成妙言点击次数。
- 有词频但含义不明：保存原始字段，不以文件位置、权重或导入时间推测真实使用次数/时间。
- 无可靠读音：后台可保存来源，但不猜多音字读音并立即投递。
- 搜狗内置词库、通讯录导入、皮肤缓存等不能冒充用户真实输入；不能判明来源的记录明确标为来源未细分。

如果当前搜狗只提供其自身可恢复的封装格式，先验证可解析性；如果借助官方账号同步到电脑再导出，必须确认同步账号与荣耀来源，且标注可能混合多设备，不能称为纯荣耀记录。Mac 来源已取消；不能擅自将本机 Mac 或账号云端的混合词库当作手机提取结果导入。当前手机本身已启用电脑用户词同步，仅凭手机页面的数量也无法证明所有词都由手机实际输入。

## 方案选择

推荐独立的公共导入词库，并保留每批来源。直接把所有手机绑定到同一个个人词库组，会把各人的管理规则和后续学习混在一起；伪造一个手机来源并批量灌入点击次数，会影响现有排序和真实习惯，均不采用。

共享的是本次明确授权导入的数据，不自动公开其他手机以后产生的个人输入记录，也不导出搜狗的账号凭据或聊天内容。

## 后台保存与迁移

公共数据不挂在荣耀设备的个人词库组下，也不以某个部署域名作为来源主键。建议增加独立的导入批次、来源条目、公共发布版本和设备回执：

- 导入批次保存稳定 ID、来源类型、来源设备说明、格式版本、文件 SHA256、导入时间、解析结果与原始词库导出载荷。载荷限定为本次词库文件，压缩后保存在 PostgreSQL，不包含整个搜狗应用目录。
- 来源条目保存原始行/记录标识、文本、原始与规范读音、已知的原始统计及字段语义。规范词条可按文本和读音合并展示，来源仍独立保留。
- 相同文件与相同记录重复导入不重复计数；新批次不能把旧批次缺项推断为删除。
- 发布版本保存启用条目与显式停用/删除状态；后台支持按来源、词语、已知统计和导入时间查看。未知使用次数显示“未提供”，不显示为真实使用 0 次。
- 导入词库载荷、来源、发布状态、版本和设备回执都进入完整数据库备份；恢复后保留原始 ID、哈希、版本和序列。只部署 Git 加空库不包含这些数据。

实际表结构和导入格式待取得荣耀导出样本后确定，避免按猜测的二进制字段实现生产解析器。

## 对所有手机生效

所有连接此后台且支持公共词库协议的妙言手机，在后台同步任务中接收已发布版本；新注册手机也从当前版本开始接收，不能仅对导入时已经存在的设备排一次队。离线手机保留已应用版本，联网后补齐。

公共词库和各手机的个人词库、个人习惯分层保存；不重新上传为该手机自己的选词记录。源使用统计可用于有边界的公共参考排序，但不能复制成每台手机的点击权重，也不能仅因导入来源就强制置顶。各手机自己的学习继续累积。

当前 `/additions` 是纯追加协议，且条目没有公共来源和撤回版本，不能单独承担公共词库的完整生命周期。正式接入需要手机声明公共接收能力，持久化公共来源及版本，支持版本化撤回/恢复和应用回执。旧手机不能只收到添加却无法执行删除；后台须显示升级要求，不能冒充已生效。

对词语的显式屏蔽独立于词库来源：公共管理中明确全局禁用/删除的词对公共接收手机生效；手机所属个人词库已禁用的词也继续屏蔽。公共重新启用不能撤销个人禁词，个人启用不能撤销仍有效的全局禁词。普通从公共词库移除来源，只移除该公共贡献，不擅自删除手机本机学习；后台须区分“移除公共来源”和“全局禁词”。

从本地/线上多个后台同步时按稳定来源和版本去重，不重复增加权重。当前两端不是数据库副本；任意新服务器必须恢复包含公共词库的数据库并配置手机可达地址，不能承诺全新空后台自动拥有历史来源。

## 性能与验收

解析、校验、来源合并和发布在后台执行。手机在同步任务中事务保存并构建索引，成功后才确认；按键路径不访问网络、不解析导出文件、不遍历全库。同步期间继续使用上一个完整有效版本。

落地时至少验证：

1. 真实导出样本能解析且抽样核对文本/读音；损坏或未知格式拒绝，不悄悄丢字段。
2. 重复导入及重复同步不增加使用次数；两个批次的同词来源仍可追溯。
3. 已有手机和新手机都收到同一公共版本，应用失败不提前回执。
4. 每台手机本机学习仍有效；个人禁词、全局禁词不被重新导入复活。
5. 公共撤回只移除公共贡献，明确全局禁词才跨全部候选来源屏蔽。
6. 完整数据库恢复到隔离环境后，来源载荷哈希、条目、状态、版本与游标一致。
7. 大库同步并发输入时测量按键到候选的延迟，比较接入前后结果；不能仅凭代码不联网宣称性能不受影响。
