# AI 合成底图库管理

目标：统一按钮与选择状态，支持上传、编辑名称/来源/文字区、替换 GIF、单张及批量删除、全选/全不选。

方案：复用上传表单作为编辑表单，选择编辑时回填资料，替换文件可选；保存失败保留草稿。新增 PATCH 接口复用现有 GIF 及文字布局校验，只更新当前用户持有的记录。替换使用新文件名，数据库提交成功后清理旧文件，避免失败破坏原图。批量删除复用逐张接口，显示成功/失败数量并保留失败选择；切换用户即停止后续请求。

范围：现有个人素材管理优先；系统只读是否放开已询问用户。默认不改变设备隔离和 GIF 格式规则，不自动发布、提交或安装手机包。

验证步骤：
1. 先添加前端编辑/全选/批量失败测试、后端编辑隔离/替换/重复/版本变化测试，观察功能缺失失败。
2. 实现 `SynthesisLibrary.vue`、`api/index.ts`、`server/src/api/synthesisLibrary.ts`。
3. 运行相关 Vitest、前后端构建；浏览器隔离 API 夹具验收桌面与窄屏按钮、保存、取消和批量删除。

用户补充（本轮）：上传选文件即入库，移除无字/授权确认勾选及二次“加入”按钮；来源说明不必填。名称默认取文件名，资料和文字区域移至入库后的编辑表单。后端同时取消确认声明校验，新上传未明确声明则记录 false，不伪造确认。替换图片在编辑界面预览，保存后生效。

验证完成：前后端相关回归共 64 项通过，前端与服务端构建通过，浏览器隔离夹具覆盖即选即传、去除确认勾选、资料编辑/区域校验/图片替换、单选/全选/全不选、删除取消/部分失败重试以及 390px 窄屏。截图仅留 `/tmp/shurufa-synthesis-desktop.png`、`/tmp/shurufa-synthesis-mobile.png`。独立审查发现的旧列表覆盖和删除结果不确定问题已修复并加回归；没有改动真实图库或发布线上。
