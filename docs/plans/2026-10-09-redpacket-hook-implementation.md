# 静默群红包 Hook 实现计划

> 执行流程：superpowers:executing-plans；用户已于本会话确认先实现完整独立模块，默认关闭自动领取，手机后续连接验证。

**目标：** 提供微信 8.0.78 / 3180 的独立 Hook 模块、入站群红包识别、请求关联与领取状态机；本地测试和原证书 APK 交付。代码完成不表示手机已具备 Hook 环境或到账验收通过。

**架构：** 在现有 Android Gradle 工程新增 `redpacket-hook` 应用，与输入法 SDK 解耦。Xposed API 仅 compileOnly，由已授权的框架加载；不修改或安装微信，不新增副屏。按实际 Android 用户保存设置，只挂载微信主进程，校验 APK 指纹及反射签名，不猜测未知版本。配置 Provider 只接受同用户的模块及微信 UID。默认关闭；探针模式不发请求；自动模式只处理明确白名单群的普通入站红包，专属红包跳过。

**保护与恢复：** 独立只读无障碍保护服务只观察前台包/键盘窗口，不读正文或点击页面。服务缺失、前台未知、输入或游戏时禁止发起新请求；保护解除保留三秒冷却。入库线程仅做有界筛选/复制入队。工作线程串行处理，发起前持久登记哈希去重，结果未知不重放；业务响应和通用回调必须属于同一个请求，均明确成功才推进。缺少实时运行证据时保持关闭，不能宣称三秒必抢或省电达标。
