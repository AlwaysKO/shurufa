# 待确认聊天来源处理

目标：待确认分组中的文字、语音提示及图片均可按真实来源删除；归属面板可合并到已有会话，或直接手动确认来源名称。

根因：虚拟分组 id=-1 禁止整组删除/合并，但原 UI 仅给图片删除入口；确认归属只能选择已有目标。

实施与验证：
1. 前端逐来源新增“删除此来源”，先解析最新来源、确认其编号/名称/消息数，再调用既有删除接口。保护设备/页面切换、已合并来源、失败及统计刷新；用 Vue 交互回归验证。
2. 在已有归属面板增加确认名称；新增只作用于当前用户、指定 App、未合并待确认来源的确认接口。事务加锁，显式确认后设人工名称和 confidence=1，不按同名自动合并。后续上传不能覆盖人工名称；用独立 PostgreSQL 回归验证隔离、竞争、后续上报和移出待确认列表。
3. 构建前后端、浏览器验收、只读代码审查并按项目要求交付 APK。无数据库结构变更，不删除真实线上记录，不提交、自动部署或安装；当前工作区已有录音设置改动保留。

用户已确认“归档”指归到正确联系人或群聊下面；不新增独立隐藏归档功能。
