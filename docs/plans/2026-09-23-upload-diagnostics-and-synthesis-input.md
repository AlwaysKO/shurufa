# 上传计时与底图源文件规格（2026-09-23）

## 关键词推荐图慢

用户确认慢的是 `/stickers`。线上日志显示“流泪”“别问我”的原文件上传已走新接口并返回201；旧访问日志没有请求耗时，不能根据相邻操作时间认定上传耗时或网络瓶颈。

新增 `[upload-client]` / `[upload-server]` JSON 日志，以随机 `id` 关联。浏览器记录传输结束、总耗时、字节数和结果；服务端记录收体/解析、图片元数据、数据库锁、词组校验、文件写入、数据库保存、提交、源码清单导出及响应词组生成耗时。日志不写文件名、关键词、图片内容、用户ID或凭据。诊断接口使用后台鉴权/CSRF，额外字段不写入日志。

反向代理默认缓冲请求体，因此服务端计时不涵盖全部公网上传；以浏览器 transferMs 和 totalMs 补齐。诊断上报异步，不延长上传等待；断网或会话失效可能导致浏览器日志缺失。日志上线前的历史请求不能恢复耗时；需要刷新后真实重传并按 id 分析。不能据此提前宣称慢的问题已解决。

## AI 合成底图

取消240×240、2～100帧和250KiB的素材门槛，保存真实宽高和格式；保持GIF原始字节。前端改用二进制上传并显示进度，新增/替换后局部更新，不重新读取全库。底图描述走请求头，不混入URL日志；旧JSON接口兼容。文字区域随替换源图尺寸缩放，编辑预览使用实际宽高比例。

当前上传通道单文件10MiB；图像解码器和手机合成仍保留内存/总像素保护，不承诺无限文件。静态格式走现有静态合成路径；其他可解码多帧格式转换为GIF，保留帧和时长供手机现有GIF渲染器处理，不允许只取首帧。

Android源码同步取消下载250KiB特例、允许静态模板和取消固定帧数上限，单素材下载容量统一10MiB，保留总缓存和总像素边界。本机没有Java/Android SDK、原签名私有配置或Windows E盘，无法运行Android构建/测试及交付APK；手机升级与真机合成待验证。后台上线不代表旧APK这些限制消失。

未改数据库结构，不新增SQL迁移。所有上传回归使用隔离数据库和合成测试文件；线上不写测试图片。

验证结果：服务端相关81项、前端相关53项通过，前后端构建通过；真实浏览器隔离回归覆盖推荐图库和底图库。资源构建并行时曾触发图片测试5秒超时，降低测试并发后81项全部通过。Android测试已更新，但因缺少构建环境未运行；不标为手机验收通过。
