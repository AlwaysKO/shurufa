# 关键词组连同说法、图片删除

**目标：** 用户确认删除关键词时，删除该组说法和图片；规划词、默认同义组刷新后不复活，删除随公共图库清单迁移。沿用当前分支，不自动提交。

**设计：** 页面使用现有确认弹窗，显示组名、说法数和图片数。后端事务串行化分组编辑，删除公共组设置及原始关键词关联；独占上传删除数据库记录并通过既有附件清理队列删文件，共用图片仅去掉本组标签。系统成品沿用隐藏记录，不修改源素材。新增组删除记录（含修订标识），阻止规划词重建并支持清单增量导入；主动重新添加关键词可重建组，仅使用本次输入作为说法；已删独占图片不恢复，共用系统图片按原标签重新归组。推荐目录排除已删除组的独占图片，保留其他组及合成素材。
