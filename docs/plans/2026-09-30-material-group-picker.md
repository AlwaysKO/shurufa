# 素材库新图优先与已有关键词组选择

目标：按用户截图明确需求，素材库默认未分配、新图优先；搜索已有关键词组，点击直接分配，别名统一沿用推荐图配置，不在素材页建词或编辑同组说法。

实现：
1. 服务端 listMaterials 分页前按素材最初入库 ID 倒序（同 SHA 历史多行取最小 ID，不因重复上传或标签修改置顶），不改推荐排序。TDD覆盖分页、历史同SHA、分配筛选。
2. 前端默认 unassigned；复用 stickerLibrary 的 groups/aliases，输入搜索组名和别名，点击候选仅发送主关键词。已关联组禁重复，无结果提示去关键词推荐图维护，加载失败/未完成不能分配。
3. 关键词差量请求带 requireExistingGroups:true，事务内重新核验组仍存在，防候选过时后创建不存在的组；兼容旧调用未带标记的既有行为。
4. 前端请求/生命周期/批量互斥保留；卡片现有关联归一化显示为组名，一图多组仍支持。
5. TDD、前后端回归/build、独立审查及合成浏览器验收；不操作其他会话 Android/AGENTS 改动、不更改线上或真实素材关系。
