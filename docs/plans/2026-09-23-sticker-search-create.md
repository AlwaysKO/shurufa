# 推荐词搜索无结果时新增词组

目标：在 `/stickers` 关键词库搜索无结果时，可直接把搜索词建为词组，并打开该组补充说法和图片。

方案：复用现有新增关键词接口和校验，不增加弹窗或后端接口。按钮显示“＋ 新增词组「搜索词」”；若完整组名或说法已存在、只是被图片筛选隐藏，则显示“打开已有词组”。创建成功清除搜索和筛选并选中新组；失败保留搜索以便重试。搜索入口不改动上方新增关键词草稿。

实施与验证：
1. 在 `client/tests/content-library.test.ts` 覆盖搜索新增、已有组定位、失败保留输入，先确认缺少入口导致失败。
2. 修改 `client/src/views/Stickers.vue` 复用新增逻辑；在 `content-library.css` 适配侧栏按钮换行和窄屏。
3. 运行内容库回归、前端构建，并使用隔离 HTTP 夹具验证浏览器点击与窄屏；不写入真实图库。

范围：仅后台页面；保持当前分支与其他已有改动，不自动提交、发布或打包 Android。

验证结果：新增的 3 个场景先因缺少按钮失败；实现后内容库及关键词 API 共 36 项测试通过，`npm run build` 通过（现有大包体积提示仍在）。隔离浏览器回归通过，包括 390px 窄屏搜索建组、刷新后保留、筛选隐藏的已有说法定位和上方草稿保留；未改真实图库。
