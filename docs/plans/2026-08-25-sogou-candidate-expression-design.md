# 搜狗式候选栏与表情合成设计

日期：2026-08-25  
状态：设计已确认，待实现

## 1. 目标

在妙言输入法中文九宫格中补齐搜狗式候选栏交互和图片表达能力：

1. 候选词支持按住后横向拖动和惯性滑动。
2. 右侧关闭按钮以悬浮方式覆盖候选栏最右侧内容，图标视觉更细。
3. 根据当前输入实时显示“推荐 / AI合成 / Emoji合成”三个模块。
4. 所有图片在真正发送前使用全屏遮罩加底部确认面板二次确认。

普通输入必须始终优先。素材查询、下载、渲染或发送失败均不得阻塞文字输入。

## 2. 候选栏交互与视觉

普通候选词使用单行横向列表，支持手指按下后连续拖动及松手后的惯性滑动。滑动到末尾时继续沿用现有候选分页机制。

右侧关闭按钮不占据独立候选列，而是固定在候选栏上方：

- 点击区域约 48dp，确保容易操作。
- 实际 X 图形约 22–24dp，使用细线条。
- 按钮背景从透明渐变到键盘背景色。
- 最右侧候选词可以延伸到按钮下方并被部分遮挡，形成悬浮覆盖感。
- 候选关联状态下点击 X 的现有清除语义保持不变。

## 3. 图片面板

图片面板位于普通键盘和候选栏上方，包含三个标签：

- 推荐
- AI合成
- Emoji合成

只有当前输入能够得到图片结果时才自动展开。没有结果时恢复普通候选栏。用户可以通过右侧按钮主动收起；切换标签或收起面板不得清空当前输入。

候选词尚未上屏时，以第一候选词作为图片查询词。每次候选变化后等待约 150ms，再刷新图片，避免短时间重复请求。候选上屏后保留最后一次有效查询结果，不让面板立即消失。异步响应返回时必须核对查询版本，过期结果不得覆盖最新输入。

## 4. 推荐模块

推荐模块使用现有表情库及新的素材索引，按以下顺序匹配：

1. 精确关键词。
2. 近义词和情绪标签。
3. 用户历史使用频率。
4. 系统通用热度。

本地缓存命中时立即展示；联网后服务端结果可以补充和重排。GIF 优先排在静态图前，但相关性高于素材格式。

## 5. AI合成模块

“AI合成”是模板文字合成，不调用生成式模型。

第一版提供 60 张原创模板：

- 20 张 GIF。
- 40 张静态图。
- 覆盖开心、夸赞、嘲讽、无语、拒绝、催促、道歉、震惊、愤怒、撒娇等常用场景。

每个模板带有关键词、情绪标签、文字安全区、字号范围、字体颜色、描边和对齐规则。素材采用混合分发：安装包内置模板索引、缩略预览和高频素材，完整素材由服务端按版本同步并缓存。

列表预览阶段只把文字视图覆盖在模板缩略图或正在播放的 GIF 上，不批量重编码图片。用户选择模板后才在后台生成最终文件：静态模板绘制一次，GIF 模板逐帧绘制并重新编码。结果以“模板版本＋文字＋排版参数”为缓存键，重复内容直接复用。

## 6. Emoji合成模块

制作 48 个原创基础表情，保持聊天表情常见的情绪语义和使用习惯，但不逐像素复制第三方专有素材。

组合区分选择顺序。第一个表情决定主体，第二个表情决定融合特征，因此 A→B 与 B→A 是两张不同图片。允许两次选择相同表情，共预生成：

```text
48 × 48 = 2304 张
```

2304 张组合成品全部使用静态 WebP，并在素材制作阶段提前生成，手机端只做索引查找，不现场合成。安装包携带 48 个基础表情、完整组合索引及最高频组合；其他组合从服务端按需下载后长期缓存。服务端通过素材版本号使客户端替换过期缓存。

选择第一个表情后进入第二步；选择第二个表情后立即查表展示成品。返回上一步时保留第一次选择。

## 7. 发送确认弹层

点击推荐图、模板成品或 Emoji 组合图后，不立即发送。使用输入法窗口之上的底部确认弹层：

- 聊天界面和键盘整体覆盖半透明黑色遮罩。
- 底部白色面板带较大的顶部圆角。
- 标题为“发送到当前聊天”。
- 中间显示待发送图片；GIF 保持播放。
- 底部为两个等宽按钮：灰色“取消”和绿色“发送”。
- 点击遮罩或取消按钮均不发送。
- 只有点击发送按钮才调用图片发送能力。
- 发送期间锁定按钮并展示加载状态，防止重复提交。

发送复用现有 `FileProvider + InputConnectionCompat.commitContent` 链路。图片先写入输入法专用缓存并授予目标应用临时读取权限。目标应用不支持图片输入或发送失败时，弹层保持打开并展示明确原因，同时提供保存图片或复制图片的降级入口。

## 8. 数据与缓存

客户端维护两个相互独立的缓存：

1. 素材缓存：按素材 ID 和版本存储原始模板、推荐图及 Emoji 组合。
2. 合成缓存：按模板版本、文字和排版参数存储最终生成文件。

服务端接口负责：素材清单增量同步、关键词推荐、素材文件下载、Emoji 组合查找和使用次数上报。网络失败时只返回本地内容，不显示阻断输入的错误。

## 9. 验收标准

1. 候选栏可以连续横向拖动和惯性滑动，点击候选不会被误判成滑动。
2. X 的图形明显比当前更细，且在视觉上覆盖最右侧候选词。
3. 第一候选变化约 150ms 后图片随之刷新，旧请求不会覆盖新结果。
4. 推荐、AI合成、Emoji合成三个标签均有真实可用内容，不出现空壳入口。
5. 60 张文字模板中包含 20 张 GIF 和 40 张静态图，GIF 最终成品仍保持动画。
6. 48 个基础表情能唯一映射到 2304 张有序静态 WebP 组合。
7. 取消发送不会调用 `commitContent`；确认发送只调用一次。
8. 微信和 QQ 真机验证确认弹层、静态图发送、GIF 发送及失败降级。
9. 断网、服务端超时、素材损坏时普通文字输入保持正常。
