# 应用前台使用记录 实现计划

> **For Claude：** 必需子技能：使用 superpowers:executing-plans 来逐任务实现此计划；本会话采用 subagent-driven-development 的分工与审查。

**目标：** 用户授权后记录所有 App 的前台使用时间段，后台按设备、App、时间查询时长、次数、排行、趋势和明细。

**架构：** Android UsageStatsManager 查询系统事件，独立同意开关＋系统权限；SQLite 原子持久化游标/未结束段/待传记录，后台任务不依赖键盘打开。沿用设备身份及双目标补传，后台新增独立页面，不改变输入/位置统计。只上传结束段；断档单独记录、不计时长，从开启时开始而不回溯历史。

**技术栈：** Kotlin / Android JobScheduler / SQLite / Express / PostgreSQL / Vue 3。

## 已确认设计与边界
- 2026-09-29 用户确认所有 App 前台使用；批准系统记录、本地持久化、后台查询方案并允许实施。
- 锁屏、切换应用、后台暂停结束段。同 App Activity 切换合并；分屏按最后恢复的前台应用单一归属，不累计双份。
- 跨天按 Asia/Shanghai 分摊；查询范围按半开区间裁剪时长，明细保留原始起止。
- 数据只包含包名、显示名、起止和结束原因，不采集页面内容。独立开关默认关；需个人数据同步同意与系统权限。关闭暂停，重新开启建立新基线。
- 系统日志缺失/重启等无法确认的时间不推定连续使用；后台显示记录断档。系统调度可能延迟，展示同步时间与“只统计已结束段”。
- Windows ADB 验证版本与默认输入法；不自动安装、授予权限、发消息、清空手机、部署线上或推送。验证后原签名 APK 交付 E 盘。

## 端到端契约
POST /api/v1/mobile/app-usage/batch，X-Device-Id 沿用现有 UUID。
请求：{ records: [{ id: UUID, kind: 'usage'|'gap', package_name: string|null, app_name: string|null, start_ms: number, end_ms: number, end_reason: string }] }，每批 1..200 条。
usage 只含已结束的正时长段；gap 无包名且不计统计。成功回执 {ok:true, received:N}（支持 discarded:true）；同设备同ID幂等。记录每端独立确认，失败不删除。
GET /api/v1/dashboard/app-usage：user_id、from/to ISO、可选 package_name、page；返回 overview/apps/daily/records/total/page（细则服务端实现者负责并同步）。范围最长 366 天；统计来自 SQL 聚合而非当前页。
