## 候选质量的具体来源与调整边界

手机只读诊断显示，不自然候选不全是运行时拼接。与锁定来源 SHA256 核对后确认：

| 候选 | 原始词表 | 原始频率 |
| --- | --- | ---: |
| 很累 / 很雷 | base | 58115 / 11 |
| 每一个 / 没一个 | base | 500354 / 111111 |
| 又没歪 | ext | 100 |
| 美一个 / 梅溪河 | tencent | 100 |
| 你赢了 / 你醒了 | ext | 100 |

公开索引只保留“是否收录”，丢弃来源及词频；基础词库、公开补回词和原生候选采用不同的分组/排序。因此低频或扩展词仍会出现。表中数字跨词表不可直接视为同尺度，不能简单用 100 为阈值删除，否则“你赢了”等正常短语也会被误伤。

手机真实历史还显示：“原装”在同码约 23 小时内被选用一次，因此按既有 24 小时近期选择规则优先；“没一个”也有真实选词记录。原生候选“幸福/应付”等同码词的差异不能仅以某一次用户选择断定前项错误。必须区分一般默认词频与个人真实习惯。

“也正常”已在手机，且有手动 preferred 标记；“也正啊”也作为旧选择词保留。不能把此状态解释为后台词仍未同步，也不能擅自清库解决。

用户之前要求影响其他输入先确认。本轮已提出范围：未曾选用的低频/扩展词默认后移，保留翻页、手工词和真实习惯。尚未得到答复，性能修复保持原排序；不单方面缩短 24 小时规则、不新增黑名单、不删除公开词或手机数据。
