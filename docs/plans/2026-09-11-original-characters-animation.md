# 原创角色动态首批

用户要求继续三种原创角色。首批各制作一张：心累、加油、期待。旧图不变，不自动发布APK/API。

1. 内置图像工具以各自原创角色稿为参考生成4×3十二姿势母版，分别强调疲惫、真诚鼓励、期待，不套同种滑稽表情。
2. 测试先验证新三词与ai-original来源被现有固定清单拒绝；最小扩展独立原创列表，来源按固定项匹配，不把梗参考洗为原创。
3. CLI新增固定original01批次，沿用240像素、20帧、4秒与原质量门禁；完整来源、提示词、SHA与动态预览隔离保存。
4. 实际成品审计、抽帧检查、定向测试及构建验证。
