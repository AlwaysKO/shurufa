# 微信会话列表内容去重

用户追加要求：本轮先不打包；先排除底部导航红点/按钮变化，再对同一列表内容跨返回去重。新会话、预览、会话未读数、时间和滚动后新露出的内容都保留。不增加截图冷却时间；逐行去重、排序与折叠置顶归并留后续。

设计：在原始截图上识别完整底部四导航布局，计算标题栏下沿到导航上沿的精确像素摘要。只在同帧确定为微信列表时使用该摘要；未知布局、聊天和其他页面保持原有行为。保留原图及真实附件 SHA，列表摘要仅用于消息指纹。

三个入口（可读树固定页面、空树 OCR、通知补偿）使用相同标题栏计算、导航证据、列表身份及消息指纹。已确认列表重复时不触发普通聊天的身份确认重放；复用现有持久 seen_message，跨返回/重建协调器去重。首帧未知不能借后帧的列表身份改变已保存图片指纹。

实施与验证：
1. 添加导航变化、正文末行/未读数/时间微小变化、未知布局等原始像素回归，先验证失败。
2. 接入列表候选摘要及三个入口，增加指纹和协调器持久去重回归，覆盖身份重放及跨入口。
3. 扩大采集回归、独立审查、diff 检查。按用户最新指令暂不构建 APK。

本地只读查看已有列表截图以核对导航布局，不修改数据库、截图、手机或线上数据；真实截图不作为提交的测试夹具。严格布局识别失败时保留截图，不用相似度阈值吞掉新内容。
