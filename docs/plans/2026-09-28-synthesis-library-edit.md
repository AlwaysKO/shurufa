# AI 合成底图库共享与编辑

2026-09-28 用户明确要求：所有合成底图均可编辑；合成底图供所有设备共用，不区分设备；修复后部署并提交 Git。

## 根因

原后台将系统底图设为只读，上传素材按选中设备筛选。线上4张上传记录属于ELI-AN00，用户查看后台时选中BSN-AN00，因此看不到。上传记录和原文件未丢失。

## 实现

- 后台与手机共用底图列表，历史上传不再按设备过滤，保留原ID、原文件及来源字段；同SHA系统底图不再隐藏历史上传条目。
- 系统与上传底图均可编辑名称、来源、文字区域及替换图片。系统首次编辑建立共享编辑副本，保留目录ID，不改写系统原文件；保存结果对所有设备生效。
- 上传、编辑、删除上传图及排序均为共享操作。新上传采用固定公共归属去重；历史记录保留来源字段，不迁移或删减图片。
- 排序使用一个公共记录，033迁移稳定合并历史设备顺序且不覆盖已存在的共享排序。后台选择不同设备不再改变底图列表。
- 图片访问仍需合法设备身份或后台身份；共享仅限合成底图库，不扩大聊天、词库等数据范围。
- 删除设备不再删除合成图片和排序；旧文件清理仍检查共享图片引用。

## 迁移与发布

新增032_synthesis_system_edit.sql：新增可空system_asset_id和唯一索引，保存共享系统图编辑。
新增033_shared_synthesis_library.sql：历史排序去重并集；保留原记录，重复执行不覆盖后续修改。

用户本轮已授权线上迁移、部署与Git提交。按既有main部署流程备份数据库、执行迁移、切换版本并检查健康和实际列表。共享上传文件继续位于持久化uploads目录，不随版本切换删除。

## 验证

覆盖系统编辑和替换、手机目录更新、静态素材、跨设备历史上传可见/编辑/删除/下载、排序同序、迁移幂等性以及删除设备后共享素材保留。真实PostgreSQL测试使用独立测试库/临时实例，不复用线上数据库。

仅后台与服务端变更，不涉及Android源码或APK打包；手机实际刷新和合成显示须与服务端接口验证区分。
