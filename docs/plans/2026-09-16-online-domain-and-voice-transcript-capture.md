# 线上域名迁移与微信语音转文字截图

## 目标

1. 线上目标未明确确认成功时，聊天文字和截图永不因时间到期删除。
2. 后台可设置新的线上 API 根地址，手机从当前线上后台取得配置并把尚未确认的线上队列原子迁移到新地址；电脑目标不受影响。
3. 用户点击微信收到语音旁的“转文字”后，在文字渲染完成的时间窗口补截当前聊天画面；相同画面继续按 SHA-256 去重。

## 设计边界

- 队列是否可过期只看持久化的 `online_confirmed_at`，不再在运行期依据“缺少某个 URL”推断线上成功。域名只是地址，不是成功状态。
- 后台地址只接受 HTTPS origin（无账号密码、查询、片段和业务路径）。手机先向当前地址读取配置，验证后持久化，再在一个 SQLite 事务内将事件和报告的旧线上目标替换为新目标。旧域名必须至少在迁移窗口内可达；已经失效的域名无法自行告诉手机新地址，只能通过新 APK 或端侧应急配置恢复。
- 微信普通节点树由内容变化事件截图；荣耀空树设备把“转文字”点击作为明确聊天动作，在短延迟和较长延迟各截一次，前一张未完成或画面相同不会阻止最终文字变化后的新截图。

## 验收

- 单元测试覆盖：线上未确认超过七天仍保留；域名变化时旧线上目标迁移、电脑目标保留；非法地址拒绝；“转文字”只在微信空树点击触发，并返回有界延迟序列。
- 服务端 API 测试覆盖后台读写、移动端读取和非法 URL；前端构建覆盖设置表单。
- 无手机时完成 JVM、服务端和网页自动验证；真机截图留待次日用户验证，不把模拟测试表述为真机通过。
