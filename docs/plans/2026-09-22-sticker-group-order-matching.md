# 关键词推荐图排序、说法编辑与完整表达匹配 实现计划

> **For Claude：** 使用 superpowers:executing-plans 逐任务实现；本会话按 superpowers:subagent-driven-development 将 Android 独立任务交给实现者，主代理负责服务端及后台，随后分别进行规范和质量审查。不创建 worktree，不自动提交已有工作。

**目标：** 图片拖拽排序与同组说法增删改持久化并同步手机，自动推荐仅匹配完整表达。

**架构：** 用户级语义组设置覆盖默认别名和图片顺序，保持原图与原始标签不被破坏。后台、手机完整目录使用相同组定义；目录增加 recommendationGroups（keyword、aliases、assetIds），版本摘要包含配置。Android 自动推荐使用完整输入与精确别名，手动搜索保留原宽松能力。

**技术栈：** Vue 3 / TypeScript / Express / PostgreSQL / Kotlin / kotlinx.serialization。

## 已确认设计（2026-09-22 用户“可以”）
- 拖拽排列组内图片并保存，未手动排序时个人上传在前；自定义顺序优先，不擅自排序左侧组。
- 同组说法可新增、编辑、删除；组标识稳定，删除说法不删除图片。配置仅作用当前选中用户。
- 手机同步后的完整组配置是匹配权威；删除说法不得被旧标签、内置别名、查询缓存补回来。
- “给你点赞”允许推荐赞组，“这是中华人民赞扬的美德”不推荐赞组。不是限制字数，也不是任意截取子串。
- 自动匹配只忽略首尾空白及句末标点，不抹除句中标点拼接误匹配。读取完整输入，不仅最近上屏片段；不能确认完整内容时不冒充完整表达。
- 手动搜索可保持宽松召回，精确命中组时使用保存顺序。
- 沿用现有打开键盘检查版本与完整目录缓存；离线保留最后有效配置，不承诺服务端保存瞬间推送手机。
