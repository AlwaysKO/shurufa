# 网页登录与可靠双端同步设计

用户已确认：登录只在网页后台；本地 admin/adminhaha，线上独立配置；电脑不可达不阻塞线上，恢复后补本地。采集需首次明确确认，可关闭；保留敏感输入过滤，不采集认证秘密。

保留现有 local_input.db 的事件及学习数据，增加通用持久上报队列，位置与候选反馈等先入队再发送。目标分别确认、稳定请求 ID 幂等、每轮限量、网络恢复唤醒与后台周期重试。线上 API 为 https://my.dog8ball.com；本地 API 默认为 adb reverse 的 127.0.0.1:3000，5175 仅为网页看板。查询主地址使用线上，避免电脑断开时失效。

网页使用服务端会话和 HttpOnly Cookie；保护所有 dashboard 接口，退出撤销会话，生产拒绝本地默认密码；不把后台账号写入 APK。静态私有资源也需核查授权路径。

测试覆盖未登录拒绝/登录退出、断网重启/独立确认/幂等/限流、授权前后与敏感输入；执行前后端构建及 Android 单测、APK 打包。如无真机或线上部署权限，明确报告未完成的真机/生产验收。
