## 生效边界
- 严格纠错依赖既有、已获同意的完整编辑快照。关闭采集、密码/禁止个性化输入、快照不可读或插入位置歧义时，不猜测纠错；允许正常学习的场景仍沿用正常学习，不能宣称所有输入框都已具备纠错识别。
- 只处理升级后的新操作，不追溯扣减旧错误学习，不删除原有词条，不修改Rime内部学习。
- 临时奖励ID仅由一次成功的上屏生成、被消费的选择不会重复生成；终态ID不作为跨进程重放接口使用。同步只看正式学习，因此没有负次数或重复扣减。
- 系统时间异常可能漏撤销/延后正式结算；严格纠错的实际2/15秒窗口不会因墙钟回拨扩大。
- 上线先迁移服务端026、更新API，再安装此APK。旧APK保持兼容，但不会自动获得短码学习；新旧服务器混用时旧端可能拒绝短码批次，需一并升级，不能把本地代码修改当线上已生效。
