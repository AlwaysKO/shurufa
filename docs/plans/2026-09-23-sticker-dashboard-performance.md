# 后台关键词推荐图库性能优化（2026-09-23）

范围：后台 `/stickers` 新增关键词和上传图片。用户授权优化、提交并推送；不修改 Android。

## 诊断与改动

线上只读测量时，约 320 个词组的完整图库 JSON 约 188 KB；服务器侧读取约 37～92 ms。该时间不包含用户网络与浏览器渲染，不能据此代表用户端等待时间。生产发布目录没有 `.git`，源码图库导出在生产会跳过，不能将全库导出当作本次线上卡顿原因。

- 浏览器原先解码图片，再逐字节构造字符串转 Base64；现在用原文件二进制上传，省掉主线程转换和约三分之一的编码膨胀。服务端继续验证格式和尺寸，不重新编码图片，保留 GIF 原始字节；兼容旧 JSON 上传入口。
- 新增和上传响应带回完整词组，页面只更新该词组，不再等待全库 GET、整体加载与重新渲染。服务端目前仍通过完整图库组装权威词组，可根据实际规模另行优化查询。
- 图库 GET 启用 gzip。推荐素材使用一天浏览器私有缓存，系统素材预览附内容哈希，用户上传素材保持唯一文件名。鉴权继续保留，聊天附件仍为 no-store。
- 上传显示字节进度，100% 后等待保存响应；失败保留当前图库并恢复按钮。超时提示先刷新核对保存结果，避免直接重试重复添加。
- 写原文件使用异步文件操作；图库相关 JSON 响应增加 Server-Timing，便于区分服务端时间与网络/渲染等待。

## 验证

正式回归覆盖：原图字节不变、返回词组说法、旧上传入口、鉴权与来源校验、格式/大小/无效词组拒绝、gzip 内容一致、推荐图缓存、聊天隔离与不缓存、上传进度/401/超时。

浏览器隔离夹具验证新增/上传不请求全库、上传失败不丢已有图片、按钮恢复，并继续覆盖排序、说法编辑、删除确认、搜索和窄屏。真实线上只进行读取及响应头验证，不写入测试词或图片。

本轮在隔离 worktree 开发：现有自动部署会 reset 共享源码目录，可能覆盖尚未提交的修改。部署脚本未在本轮修改。
