# Git 素材瘦身与历史重置计划

> **For Claude：** 必需子技能：使用 superpowers:executing-plans 来逐任务实现此计划。

**目标：** 制作图片只在本地保存，远端保留最终导出 GIF、必要记录与运行资源；清空旧历史，实测新克隆大小。

**架构：** 用路径限定的 .gitignore 排除制作中间媒体，不影响应用资源。以原 HEAD 为基线创建无父提交，仅加入本次规则；保留当前工作区及其他未提交改动。带远端旧 SHA 校验强推 main，验证远端克隆后回收本地旧对象。

**技术栈：** Git、Markdown、现有素材生成脚本。

## 步骤与验收

1. 记录本地/远端 SHA、索引与工作区文件哈希；确认仅 main、无标签、没有暂存改动。
2. 更新 .gitignore、AGENTS.md 和 CREATION-POLICY.md；制作区域排除非 GIF 媒体及 rejected/masters/poses/frames 下的 GIF，保留 JSON/Markdown 等记录。
3. 用 git check-ignore 验证新规则；临时索引从 HEAD 删除匹配文件，不删除本地文件；只加入本次规则文档。
4. 创建单次无父提交；验证保留的运行素材来源和 GIF 完整。制作原图不随克隆，因此旧素材重绘及依赖原图的验收需从本地归档补回，不能宣称全套创作测试无须原图。
5. 用 --force-with-lease 精确更新远端 main；不纳入其他开发改动。同步本地 main 与索引，保持工作区内容。
6. 全新远端克隆：确认仅一个提交、没有制作中间媒体、统计 .git 与文件大小；验证正式素材生成链路。
7. 验证完成后清空本地 reflog 并回收旧对象；核对原本地文件未丢失。规则写入 Vault 索引；告知其他电脑应备份改动后重新克隆。

## 长期边界

只提交导出 GIF 不等于通过视觉验收或批准发布。保持必要运行静态资源；不提交新中间媒体、不用 git add -f 绕过规则。Git 随新 GIF 与版本增长，不承诺固定体积；本次历史重置授权不等于以后自动强推授权。
