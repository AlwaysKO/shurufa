# 搜狗式图片推荐交互与键盘布局优化设计

## 背景

当前图片表达工作流已经具备推荐、模板、Emoji、预览确认和图片发送能力，但真机对照搜狗输入法后暴露出七类体验差异：拼写阶段过早推荐、标签缺少选中反馈、推荐区不能展开、模板素材上方留白过多、推荐与输入词无关、候选关闭区透明、中文和英文键盘几何不一致。

本次修改在当前 `main` 分支直接完成，不创建 worktree；所有提交只包含本设计直接涉及的文件，不覆盖或混入工作区已有未提交修改。

## 已确认的产品行为

1. 拼音组合和候选变化只负责清除过期推荐，不触发搜索。
2. 只有候选词真正上屏后，才以最终上屏文本发起推荐查询。
3. 推荐只返回与完整词语精确关联的预制图片；没有匹配时隐藏推荐区，不按热度或模板兜底。
4. 推荐图片直接发送原始素材，不把刚输入的文字再次合成到图片上。
5. 模板标签仍支持把文字覆盖到图片内容上，但素材构图不再为文字预留大块上方空白。
6. 推荐初次出现为紧凑单行；再次点击当前标签或切换标签后展开为可纵向滚动的多列网格。
7. 推荐、模板和 Emoji 均使用明确的选中文字颜色和底部指示线。
8. 候选栏右侧关闭区域使用不透明背景，完整遮住其下候选文字。
9. 中文九键、中文全键和英文全键的键位几何按已连接手机上的搜狗布局校准；保留项目现有配色、图标和输入逻辑。

## 架构设计

### 1. 提交事件驱动推荐

`ExpressionQueryCoordinator` 不再接收“首候选”作为可发布查询。组合态变化统一调用 `onComposingChanged()`：取消待处理查询、使旧响应失效并通知界面清理；最终候选上屏统一调用 `onCommitted(text)`：防抖后发布唯一查询。

`InputView.chooseAndUpdate()` 是候选最终上屏的公共出口。推荐通知在这里集中触发，覆盖点击候选、空格确认、标点前自动确认等路径，避免只修复某一个点击入口，也避免重复发布。

### 2. 精确的预制推荐

服务端和 Android 离线目录采用相同规则：只保留 `keywords` 中与完整查询相等的素材，再按热度和目录顺序排序；未知词返回空列表。

源清单为常见词语配置多张语义匹配的原始素材，例如“你好”“谢谢”“加油”“晚安”等。推荐结果在传输层标记为 `type = recommendation`，模板目录中的同一素材仍保持 `type = template`。因此推荐点击直接使用原始文件，模板点击才调用 `ExpressionRenderer` 合成文字，不需要额外维护两套位图。

### 3. 紧凑与展开两态面板

`ExpressionPanelState` 增加 `COMPACT`、`EXPANDED` 两种展示状态。新查询和清理都回到紧凑态；当前标签再次点击或切换标签会进入展开态。

`ExpressionPanel` 根据状态切换布局：紧凑态使用单行横向列表和 116dp 内容高度；展开态使用三列纵向网格和约两到三行可视高度。Emoji 标签沿用现有选择器，但共享展开高度和同一标签选中样式。

### 4. 素材构图与文字覆盖

源素材生成器支持 `sourceCrop`。现有 384×384 联系表单元统一裁去上方冗余背景后再放大到 512×512，使主体占据画面；文字安全区仍位于图片内部，渲染器直接把文字覆盖在画面上，不拼接独立文字区。

生成测试验证裁剪参数有效、输出尺寸不变、目录数量不变。重新生成服务端运行时素材和 Android 内置素材后，资源审计继续保证哈希与清单一致。

### 5. 搜狗式键盘几何

新增纯规格对象 `SogouQwertyLayout`，集中定义：

- 三行字母键宽、第二行起始偏移、Shift/Delete 宽度；
- 七键底栏（符号、数字、逗号、空格、句号、中英切换、回车）及各自宽度；
- 横纵按键间距缩放。

中文全键和英文全键共用该规格。中文九键保留已实现的列宽和键位，仅按真机截图微调纵向间距。几何通过 JVM 单元测试锁定，真机构建后再与搜狗截图对照。

## 测试策略

严格按 TDD 分阶段进行：每个行为先增加失败测试并确认红灯，再写最少实现、确认绿灯、提交。

- Android 纯逻辑：提交触发、过期响应、精确推荐、面板展开状态、推荐不合成文字、键盘几何。
- Android Robolectric：标签选中状态、横向/网格布局切换、候选关闭背景不透明。
- 服务端 Vitest：精确命中、多结果排序、未知词空结果、推荐类型。
- 素材生成测试：裁剪参数、输出尺寸、清单数量与资源哈希。
- 完整验证：服务端测试与构建、Android 单测与 APK 构建、素材审计、连接手机安装和关键交互复测。

## 非目标

- 不复制或抓取搜狗受版权保护的表情素材。
- 不改变项目主题颜色、品牌图标、输入法词库或候选算法。
- 不为未知词动态生成推荐图，也不回退到通用热门图。
- 不修改与本任务无关的采集、位置、Dashboard 或设备隔离代码。
