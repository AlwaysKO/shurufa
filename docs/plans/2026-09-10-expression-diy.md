# 相关表情模板与整句DIY闭环

用户已明确：句子提取核心动作/情绪，同近义词找相关图；点击模板把完整原句贴在图上并可发送。不是文生图，不是仅做超时退出。

证据：当前同义规则已有打我/打你，但正式172项图目录无任何打闹/追赶关键词素材；AI标签展示全部模板不做匹配；推荐模板副本originalForRecommendation还会阻止点击时叠字。必须同时解决素材覆盖、候选筛选和真实渲染闭环。

实现：
1. 双端共享关键词/同义规则回归覆盖用户原句、否定、电话等歧义；无相关图不凑数。
2. AI标签只显示当前句子相关且具有布局的合成模板，不能浏览全库作为候选。
3. 推荐阶段只展示原图（避免昂贵即时编码），点击模板必须叠加完整原句；预制带字图仍维持原图发送，避免叠两层文字。
4. 原创动作素材选择须可追溯且画面真相关；待审核批次不默认为已发布。先确认可用素材再接入正式数据，不乱给旧情绪图加动作标签。
5. 用实际素材+中文原句在native graphics渲染产生真实成品，检查尺寸、文字像素、原句传递、文件可读、发送使用成品而非原件。运行定向测试和构建，不将超时恢复当成功验收。
