# 整个后台响应式适配设计

## 已确认范围

2026-10-14 用户确认：整个后台同时适合手机和电脑；手机保留编辑、上传、删除、筛选等全部现有操作，不做只读版。使用同一套 Vue 页面，不新建移动端项目，不改变业务、权限、数据范围或接口语义。尚未授权 Git 提交、推送或线上部署。

## 现状与选择

- `client/src/main.ts` 共 27 条路由（包括登录）；高频词句与常用语复用 Phrases 页面。
- `App.vue` 的侧栏在窄屏仍占 190px，内容区被挤压。
- `content-library.css`、`PageCaptures.vue`、`VideoVisits.vue` 各自通过 `.layout:has(...)` 改写全局外壳，需统一而非继续叠加例外。
- 部分页面已有响应式网格、表格滚动和弹窗样式，保留有效规则，仅修复实际问题。

选用同源码响应式：成本和维护风险低，功能一致。仅缩小电脑页面不能解决触摸和阅读问题；另建手机版会重复维护功能、权限及错误状态，均不采用。

## 布局与交互

1. 桌面保留侧栏。窄屏（初始断点 760px，测试边界）提供顶栏和抽屉菜单，保持全部菜单与分组；路由切换后关闭。支持遮罩、关闭按钮、Esc、焦点进入/返回及阻止背景交互；旋转到桌面不能遗留滚动锁。
2. 内容区可收缩但不通过全局隐藏溢出来掩盖问题。筛选、分页和操作区换行；统计和双栏区域在手机堆叠；长文本断行。
3. 图片/记录卡片维持卡片形式。复杂表格保留语义和完整字段，以可聚焦的局部横向滚动区容纳，不复制两套业务模板；不能把删除等列直接隐藏。
4. 登录、设备目录、编辑/上传、图片预览及确认弹窗保持屏内，长内容内部滚动；按钮易于触摸，表单避免固定最小宽度撑开页面。目录编辑、切换设备与危险操作确认沿用原行为。
5. 图表和地图适应容器尺寸变化；图片保持比例。触摸操作不要求 hover，不阻止浏览器缩放。

## 数据与错误边界

仅布局和导航交互变化；不新增后端接口/迁移，不修改权限。保留鉴权失效跳转、旧设备响应保护、局部分页、加载/空/错误状态。应用使用分页只更新底部，不刷新统计和时间轴。浏览器测试用虚构接口数据，不对真实设备执行编辑、上传或删除。

## 验收

覆盖路由清单全量检查，视口 360×800、390×844、768×1024、1440×1000；补充断点前后、横屏和宽窄往返。使用有数据、长字段、空和失败状态，不能仅凭空白页面截图宣布完成。检查页面无横向溢出、局部表格可滚动到操作列、抽屉全部入口可达、表单与弹窗可操作。构建、现有前端测试、相关浏览器业务回归和截图目视检查分别记录。浏览器模拟通过不等于手机浏览器真机验收，部署亦单独报告。
