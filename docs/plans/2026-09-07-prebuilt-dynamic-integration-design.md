# 首批预制动态 GIF 正式接入设计

用户已于 2026-09-07 确认此设计。在 main 上增量开发，保留 70b1eef 及全部祖先提交，不使用 worktree。

## 方案

在 `assets/expression/manifest.source.json` 增加独立 `prebuiltAssets`，登记通过视觉验收的 12 张 GIF，不复用模板生成配置。运行时沿用 `type=prebuilt`、`format=gif`，固定 `embeddedText`，`textSafeArea/layout=null`。文件按已验收 SHA-256 校验并原样复制；首帧生成 WebP fallback。源配置保存关键词、风格、来源类型及来源/许可证或原创提示词记录。

相比新增 curated 运行时类型，此方案复用已有加载与发送能力，修改更少；相比伪装成模板产物，明确区分源数据并杜绝手机首次重新编码。

## 排序与兼容

新项按每词四个不同风格登记，优先于旧静态预制项；服务端与 Android 使用一致规则并以真实 catalog 回归测试保证前三个词的前四项。保留旧项和现有模板行为，不重构性能机制。离线预制项不进入 resolver 的生成路径；GIF 失败使用首帧缩略图，发送原始 GIF。

## 门禁

数量预期从源清单计算，保留 synthesis、animated、prebuilt、Emoji 数量和组合完整性校验。独立 GIF 校验来源类型、哈希、240×240、10–20 帧、800–2000ms、循环、低于 250KB。生成器写出服务端 runtime 和 Android catalog，内置文件逐字节一致。

## 验证与交付

执行用户指定服务端、prototype、正式生成及 Android 相关测试和 APK 构建。真机安装、录屏/抽帧、标签切换恢复和发送文件检查，最终恢复搜狗默认输入法和关闭常亮。交付新增 12 项、首帧联系表、尺寸/帧数/时长/大小/哈希、测试记录和提交号。第一阶段通过后仅编写 100 个高频词及分批风格方案，等待用户确认，不生成 400 张。
