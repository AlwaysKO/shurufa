# 微信收藏表情导入与素材管理设计

日期：2026-09-29。状态：已实现并通过本地分层验证，尚未部署线上；线上实际图库导入待发布后验收。详见 `docs/testing/2026-09-29-wechat-sticker-import.md`。

## 用户确认的目标

在已登录微信的电脑上获取收藏表情，线上后台点击一次导入：先与**线上实际图库**比对，已有图片不重复上传，展示已有全部关键词；新图片进入未分配列表。后台可预览原始 GIF、按分配状态筛选、为一张图增加多个关键词。用户不再逐张导出或上传，也不需要连接手机。

用户已接受“本机导入助手 + 线上后台按钮”。本轮确认不等于授权自动推送 main、发布线上、修改线上数据库或把未分配图片加入推荐。

## 沿用的项目协议

- `AGENTS.md`、`docs/SHARED_STICKER_SYNC.md`：公共关键词推荐图库全设备共享；不扩大至聊天或个人词库；本地图库的原图和关联元数据共同归档。线上新增不自动回写 Git。
- `assets/expression/CREATION-POLICY.md`：保留原始素材与动画；导出成功不等于发布授权；用户收藏不自动获得公开分发许可。本次是用户素材导入，不强套原创制作的尺寸、帧数和体积门禁。
- 本地 SQL 变更须核实开发数据库后执行并验证；线上迁移另外安排。
- 保留已有词组、同组说法、排序、使用次数及历史 ID；不主动合并或删除历史重复记录。

## 已完成的可行性验证与限制

- 本机 Windows 微信 4.1.13.65 已成功只读提取收藏列表及原图，362 张原图 MD5 全部与微信记录一致；236 个 GIF、93 个 PNG、33 个 JPEG。
- 359 张通过逐帧解码，其中 222 张确认为动画；3 个 GIF 严格解码报截断，保留原图并隔离，不自动作为正常导入项。
- 旧版明文密钥扫描不适用。兼容探针通过 WCDB Config.Cipher 的掩码格式发现候选，并以目标 `emoticon.db` 首页 HMAC 验证；不注入、不写微信进程、不读取聊天数据库。临时解密库已清理，密钥未落盘。
- 探针仅验证了此台电脑与当前微信版本，不承诺其他 Windows 版本或 Mac 已兼容。
- 线上 SSH 只读尝试因缺少已信任主机密钥而停止，没有绕过校验；线上现有图库实际匹配数量尚未核验。本地已归档 3 条记录中匹配 2 张，不代表线上只有 2 张。
- 导出文件、数据库、下载地址、助手配对凭据和真实表情不随本设计提交。

## 方案与取舍

采用**本机助手主动通过 HTTPS 连接线上**的方案：助手配对后定时领取“导入本人收藏表情”任务，浏览器只与同源线上 API 通信。避免让 HTTPS 网页跨域访问 localhost，也不开放本机端口、不让线上服务器接触微信密钥。

替代方案是手动选择导出文件夹批量上传，仍可去重，但不满足最终免手动导出的目标，因此只作为后续可选回退，不阻塞主链路。普通线上网页直接读取微信目录不可作为实现前提。

首次在 Windows 安装、指定微信账号目录、用后台一次性配对码连接。日常助手运行时，后台点一次即可；助手离线应明确提示，不伪装导入成功。默认不自动添加开机任务，启动方式在交付时说明。

## 数据与接口边界

### 现有图片与未分配图片

复用 `sticker` 表的原图、SHA256 和逗号分隔关键词。未分配用空字符串 `keywords=''` 表示，旧的手动按词上传入口仍要求关键词；仅素材库和导入入口允许未分配。

- 素材库按文件 SHA256 聚合显示，可展开历史记录 ID；已有多条同图记录展示全部关键词的并集，不删除或重排旧记录。
- 导入重复图片只返回已有记录及实际归属，不覆盖关键词。没有 SHA 的历史记录从已有原图补算，缺失文件明确报告。
- 关键词编辑提交显式 `add/remove` 差量：新增关联放到一个确定的已有记录；移除仅处理用户明确选择的关联。移除最后一个关联后保留原图为未分配。
- 摘要匹配仅接受 SHA256 完全相同。改文件名不影响；裁剪、转码等视觉近似不自动合并。
- 复用图库事务锁避免两次导入同时新增同图；不建立会让历史重复数据迁移失败的全表 SHA 唯一约束。
- 手机空关键词列表、搜索回退、推荐目录均排除未分配记录；素材库不依赖手机选择。
- 扩展图库清单校验允许空关键词原图归档；空关键词不能被当作一个分组，也不能在清单导入时清空线上已分配关联。增加回归验证并说明旧版程序不能处理新语义的回退边界。

### 助手与导入任务

新增配对码、助手、任务和任务条目表；它们是运行状态，不进入公共图库 Git 清单。

- 管理员同源会话可创建一次性短期配对码、查看/撤销助手、开始/取消导入、查看进度。
- 配对码有过期、单次兑换及限流；助手令牌仅授予本助手的领取任务、提交摘要、上传缺少的原图和汇报错误权限。
- 助手令牌服务端只存哈希，Windows 本机使用用户级受保护存储，不复用后台登录密码，也不使用微信数据库密钥作令牌。
- 助手只处理本机配置的账号目录；任务不接受服务器提供的任意文件路径、命令或下载地址。
- 上传前先发送 SHA256 清单；服务端返回 `existing/missing` 及已有关键词。只上传 missing；服务端独立校验内容 SHA256、格式、容量和可解码性，不能相信客户端声明。
- 任务条目以任务 ID + SHA 唯一；领取有租约、续期与终止状态。重复上传/重试不重复计数；部分失败保留已完成项，不删除已有图库。
- 进度区分发现、校验失败、已有跳过、上传新增、失败和取消；“已有”不能显示成“新增成功”。

### 本机采集安全

只读微信目标进程，候选必须匹配本地配置的表情库 HMAC。只解析收藏表情表，不提取聊天、联系人或账号密码。原始密钥不打印、不存盘、不上传，临时明文表情库在成功和异常路径均清理。

读取时考虑 DB/WAL 快照一致性，不能忽略有效已提交 WAL；无法得到一致快照时明确失败。只下载已提取的官方表情 CDN 原图 URL，校验 HTTPS、允许域名及重定向，拒绝任意网址。下载原图按微信 MD5核对，再计算 SHA256；逐帧验证不通过的文件隔离，不转静态、不改变原图冒充成功。

## 页面

在现有 `/stickers` 增加“按关键词 / 表情素材库”切换，复用已有页面入口，不新增手机选择前置条件。

素材库：一键从电脑微信导入、助手在线/离线与配对状态、导入进度；全部/未分配/已分配筛选；分页动图预览；所有关联关键词标签；关键词添加和明确移除。匹配到旧图片的卡片展示已有归属。旧的按关键词上传、排序及删除保持原行为。

第一版不做视觉相似搜索、自动猜关键词、自动合并旧重复记录、Mac 采集、远程任意文件浏览、自动开机常驻或额外 AI 服务。

## 验收

1. 用合成小型 GIF/PNG/JPEG 测试导入、同图改名、重复批次、并发上传、历史缺 SHA、多词归属和异常文件，真实素材不作为提交夹具。
2. 已有图导入前后关键词/排序/ID/使用次数不变；二次导入新增数为 0。
3. 未分配图可后台查看，但手机推荐/目录/空词列表不可获得；分配到 A/B 后两组可查，移除 A 不影响 B。
4. 配对过期/重放、错误令牌、跨助手任务、取消后的上传、助手离线和恶意路径都被拒绝，日志不含凭据。
5. 本地真实 PostgreSQL 事务与迁移验证、前后端构建、浏览器交互和助手集成分层记录。Windows 真机导出已证明可行，不替代线上完整链路验收。
6. 线上发布前备份并单独取得发布安排；用线上真实 SHA 匹配验证已有内容，禁止用本地 3 条元数据覆盖线上图库。
