## 4. 重复滚动与消息去重（待执行）

每个应用至少选择一个包含 20 条以上消息的会话：

- [ ] 首次进入后上下滚动三个来回；
- [ ] 重叠视口中的同一条消息只入库一次；
- [ ] 文本相同但实际为两条的消息均保留；
- [ ] 退出并重新进入会话不产生重复消息；
- [ ] 杀进程、重启应用后仍不产生重复消息；
- [ ] 通知重复更新只入库一次；
- [ ] 先由通知采集、后在页面出现的同一消息不重复入库；
- [ ] 仪表盘顺序、发送者、方向、类型和时间显示正确。

## 5. 媒体与版本降级（待执行）

- [ ] 同一稳定视口内多个媒体节点只触发一次截图；
- [ ] 图片裁剪不包含输入框、系统栏或其他消息；
- [ ] 相同媒体只上传一个资源，多条消息可以引用它；
- [ ] 安全窗口或截图频率错误只标记 `asset_capture_failed`，文本继续入库；
- [ ] 可读通知图片 URI 被规范化为 PNG 并上传；
- [ ] 不可读、非图片、超尺寸或超过 5MB 的通知媒体不上传，消息仍保留失败元数据；
- [ ] API 34+ 验证窗口截图；
- [ ] API 30–33 验证默认显示屏截图和坐标换算；
- [ ] API 23–29 验证不请求截图且不出现 MediaProjection 授权弹窗。

## 6. 无感与安全边界（待执行）

- [ ] 采集过程不自动点击、滚动、返回、打开会话或切换应用；
- [ ] 通知监听不取消通知、不回复、不调用通知 PendingIntent；
- [ ] 除首次系统授权外，不出现额外授权或录屏提示；
- [ ] 锁屏、安全窗口、未知页面和低置信度会话均安全跳过；
- [ ] 断网时本地入队，恢复网络后按“资源先、消息后”自动补传；
- [ ] 服务端暂时失败时按退避策略重试，无高频请求循环。

## 7. 性能与稳定性（待执行）

- [ ] 连续使用聊天应用 30 分钟，无崩溃、ANR 或明显卡顿；
- [ ] 快速滚动期间截图受 300ms 稳定视口防抖约束；
- [ ] Bitmap 使用后及时释放，长时间滚动内存不持续增长；
- [ ] 待上传资源成功确认后缓存文件可被清理；
- [ ] 记录空闲和连续滚动场景的 CPU、内存、耗电及数据库大小；
- [ ] 检查 `adb logcat` 中无持续异常、权限错误或上传风暴。
