# 行为明细分页（2026-10-28）

用户要求行为明细支持跳页等分页操作。

- 增加首页、末页、当前页附近数字页码、省略号和页码输入；按钮与回车均可跳转。
- 保持每页20组/条及当前筛选、整段/原始模式；换页沿用已有清空勾选规则。
- 空值、非整数、越界页码不发请求；加载和删除确认/执行期间禁用分页，当前页不重复请求。
- 筛选或模式切换重置跳页输入；服务器总数减少时沿用回退有效末页逻辑。
- 手机宽度下分页按钮换行，当前页高亮，显示总数、每页数量和总页数。

验证：

- `node server/node_modules/vitest/vitest.mjs run client/tests/activity.test.ts`：36项通过，包含新增分页、边界、筛选与回退场景。
- `cd client && npm run build`：通过。
- 本地构建的 Chromium 浏览器验证：1440px、390px，按钮和回车跳页、非法输入、来源筛选保留、空列表、无横向页面溢出均通过；使用合成数据，手机布局截图已人工查看。

仅修改后台前端，不修改手机采集、数据库、排序或每页数量。发布状态以部署记录与线上REVISION为准。
