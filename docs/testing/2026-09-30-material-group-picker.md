# 素材库排序、默认未分配和关键词组选择验收

日期：2026-09-30。范围仅素材库交互与列表排序，不改推荐词配置、推荐排序、真实素材关联或数据库结构。

## 改动

- 素材列表分页前按首次入库 ID 倒序；同 SHA 历史多行取最小 ID，重复上传、修改标签不置顶。
- 页面 filter/query 均默认未分配；分配成功刷新列表，从未分配列表移出。
- 卡片输入搜索已有组名和同组说法，点击候选直接分配主关键词；不再按逗号自由输入建词。已关联组禁重复，一图可选多个组。
- 标签按组归一显示；同组说法只在“关键词推荐图”维护，素材页不保存一套别名配置。
- 组加载错误提示重试，刷新重载候选，旧响应与卸载受序列门禁保护；保留批量上传和标签编辑互斥。
- 组选择请求带 requireExistingGroups:true，服务端公共锁事务内重新核验当前组，不存在返回 409，不静默创建过时候选。未带标记的旧 API 行为兼容。
