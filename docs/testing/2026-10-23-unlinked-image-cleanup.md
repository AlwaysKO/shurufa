# 未关联图片删除与保留清理

用户要求：未关联图片页提供单张、批量删除和保留1/7/30天按钮。

实现口径：

- 单张删除和勾选当前页批量删除均须确认。请求冻结选定ID和手机，服务器重新检查图片归属、类型和全部聊天关联；任一选定项不再符合条件时整批拒绝，提示刷新。
- 保留1/7/30天是一次性清理，按服务器接收时间保留最近N×24小时，不是自动定时策略。范围为当前手机和当前北京时间日期筛选，跨所有分页，截止时刻本身保留。
- 先预览数量和准确截止时间，确认后每批200张。预览冻结ID和行签名，15分钟失效；新上传图片不会加入旧预览，新关联或已变更图片跳过。最多5万张，超过时要求缩小日期范围。
- 切换手机、筛选、页码或离开页面废弃旧确认；在途批次可以完成，但不继续发送旧范围后续批次。允许停止后续批次、从已完成进度继续；相同批次重试不重复推进。
- 复用现有登录与请求标识校验、事务、附件清理清单及后台重试。提交前不删文件，提交后复核所有手机/共享素材引用，只有无引用文件才回收。
- 仅删除后台当前副本；未增加手机端删除协议或资产墓碑。手机后续补传可能重新出现，页面已说明。未更改手机采集/上传行为。

验证：

- 隔离PostgreSQL实例23项集成测试：范围、关联竞态、日期边界、权限、事务回滚、共享文件、文件失败重试、200张分批、旧offset重试、令牌归属及过期。
- 现有CaptureManagement的12项状态测试通过。
- 1440px、390px合成数据浏览器测试通过：删除确认/取消/失败重试、勾选批删、三个保留按钮、清理确认、范围切换废弃确认、列表和原图回归、手机布局。
- 前后端构建通过。真实线上数据不执行删除测试；发布后只检查页面、按钮和清理预览并取消。
