# 个人词库与换机同步

## 使用顺序

1. 后台先通过正常发布流程依次应用 `016_personal_dictionary.sql`、`017_dictionary_target_role.sql` 并部署相应 server/client。2026-09-16 本地已应用这两项迁移，不代表线上已部署。
2. 旧手机**覆盖升级**支持本功能的 APK，不卸载、不清数据；开启已有「个人数据同步」开关并联网，先让旧记忆完成备份。
3. 新手机安装新版、启用输入法并允许个人数据同步。首次初始化会尝试读取系统公开词典，受权限及手机实现限制；不会读取搜狗等私有学习库。
4. 登录主控后台，在顶部设备目录选择旧手机，打开「个人资产 → 个人词库与换机」。默认仍以线上为主控；本地电脑接收独立备份，可切换设备查看新旧手机上报，但不下发管理决策。
5. 查看新旧手机的型号、设备编号、最近上报时间。选择新手机的「绑定到当前个人词库」。如果该手机已绑定其他手机，确认框会说明整组合并；先确认设备属于同一人。
6. 使用「各手机原始上报」查看来源明细，或「按词合并查看」去重查看词语。可按手机、词语、拼音、状态筛选，分页和批量保留/停用/删除。
7. 后台显示「等待手机同步」时还没有生效确认；手机联网且后台任务获准运行后恢复，确认版本后显示「手机已确认应用」。Android 省电策略或关闭同步可延迟执行，不能承诺实时推送。

## 数据含义

- 实际选词记录：输入码、次数、衰减权重与最后使用时间。
- 词条读音：文本、已知拼音及来源。系统导入不伪造选词次数，未知读音显示「未记录」。
- 同一词有多设备/编码记录是正常来源明细，不代表重复点击。恢复层不再次上报为本机来源，重复传输不叠加次数。
- 停用/删除按词作用于此共享个人词库的所有读音和编码。原始上报保留可查，决策标记防止重导入复活；明确恢复才重新启用。
- 这不是全引擎禁词功能。公共词典中的正常同名词、原生引擎独立记忆仍可能显示；本功能管理 App 个人词条/选词补充层，不迁移其他输入法私有模型或 Rime 模型文件。
- 词库向线上与当前配置的电脑地址独立上报，各自保存凭据、上传进度和重试状态；旧版线上凭据保留。只从主控后台恢复和确认，另一端显示「仅备份」，禁用绑定/保留/停用/删除，避免让用户误以为操作已下发。主控离线时不自动改用备份端决策。
- 导出个人数据经过敏感文本过滤，但不能声称能识别所有未标注敏感内容。原有个人数据同步同意开关继续生效。

## 本地看不到上报时

先区分设备注册/输入事件与个人词库：设备在线不代表词库已收到。电脑地址使用手机侧 `127.0.0.1:3000` 时，需要项目既有 Windows→WSL relay 与 ADB reverse；重启 WSL 或重新连接 USB 后检查该通道。局域网直连则检查地址可达性。

本地 API 必须完成两项词库迁移。手机须覆盖安装包含双端词库上报修正的 APK；此前仅线上同步的版本不会因本地服务修好就开始传词库。不要卸载或清数据来排查，否则可能丢失未备份的学习记录。

## 换机注意

新版用不参加备份的设备锚点区分手机，首次升级仍保留老设备编号。系统备份排除本机来源学习库、待传队列、同步凭据和旧迁移状态，防止新设备重复计数或跳过公开词典检测。其他键盘设置仍遵循系统备份。

因此应先升级旧手机并确认上报成功，再更换手机。未上传数据、旧版本生成的系统备份、忽略 Android 排除规则的第三方克隆工具，不保证恢复。不要以直接复制 `local_input.db` 或设备偏好替代此同步流程。

本功能尚无解除绑定或撤回已离线下载数据的管理入口；绑定前核对设备。复制设备编号不能替代同步凭据；初次凭据采用首次注册绑定，不代表硬件可信认证。
