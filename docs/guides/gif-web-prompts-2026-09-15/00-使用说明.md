# 剩余 GIF：ChatGPT 网页制作提示词包

日期：2026-09-15。此包只整理文字，不生成图片、不修改旧图、不接入APK/API、不发布。

## 直接开始

1. 打开 [原300词表：206组提示词](01-原300词表-206组提示词.md)，选择一组，将其完整代码块复制到 ChatGPT 网页的一个新聊天。
2. 提示词要求生成**无字幕的12格PNG姿势母图**，不是让网页直接交付已验收GIF。每个角色/风格一张独立4列×3行母图，不能把四种风格拼成一张。
3. 如果一次只生成一张，保留这个聊天，发送下面的“本组下一张”。不要每次重贴整个组导致重复生成。换组再开新聊天，避免角色与动作混淆。
4. 下载原始图片，按提示词中的名称保存，如 `K005-A.png`。保留实际使用的提示词；如果自行改了角色、动作或尺寸，也一起说明。
5. 生成后把这些原图交回来。我再按实际源图检查格子、角色连续性和安全区，补中文、合成GIF、压缩并制作首帧WebP。需要扩展现有固定清单后才能导入，不会把网页输出自动视作合格。
6. 实际播放、情绪表达与审美仍需审核。不要只因为图片“有12格”就认为动画会自然。

**不用另外拼接通用提示词。每组代码块已经包含角色、表演、风格、12格节奏和安全区要求。**
每组文件编号沿用原分组序号，因此可能跳号，不是漏组；完整盘点在第三份文件。
每组只做“本次新做”的数量，已存在的图不重复、不覆盖。

### 一次只出一张时，复制这句

```text
请继续本组下一个尚未生成的方案。沿用本组的意图、12格表演和输出规则，只生成该方案的独立4列×3行PNG母图，不重做前面已生成的方案，不把不同风格合成一张。在图片外注明当前方案与保存文件名。如果本组已经全部完成，告诉我已完成，不追加新图。
```

这只是分次操作方式，不保证网页会一次生成多份、严格给定尺寸或完美执行网格；需要检查实际下载结果。

## 每次下载后检查

- 是4列×3行的12个等大正方形格子；不是12种无关情绪。
- 同一张母图只有指定角色/同伴，身份、服饰、身体比例不变。
- 眼神、眉眼、嘴形和肢体共同表演。第7、8格保留关键动作，第9—11格逐渐回正。
- 三行内主体的相对位置一致，最后一格回到第一格；没有逐行上移、越格残片或裁耳。
- 字幕区没有手掌、手指、爪或重要道具，底部白色区域留足。
- 不要让网页生成中文字幕、水印、格子编号或版权角色。
- 失败图原样留存并标“失败”，重新生成另存新版本，不能悄悄覆盖。

导入后的目标仍沿项目要求：240×240、约4秒、20帧、循环、低于250KB、首帧WebP。机器检查不能替代真实播放和用户对情绪的认可。

## 归档边界

人物一律原创中国成年男性；不借明星脸/IP微改。来源提示词和原图均保存，导入时计算SHA。
依当前项目政策，制作PNG母图、抽帧、预览、废稿只在本地保存；Git只接收最终导出GIF与必要代码、文字、清单。此提示词包不改变发布门禁，也不自动审批旧候选。
