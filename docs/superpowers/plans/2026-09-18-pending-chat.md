# 聊天首帧保留与待确认统一展示实施计划

**Goal:** 微信/抖音进入聊天无需点击输入框；首图不等名称确认；未确认图片每手机每App统一入口；QQ识别不改。
**Architecture:** 保留客户端独立临时身份与已有确认补传协议；后台仅虚拟聚合，不按名字或低置信度强行合并数据库记录。首图先持久化，确认失败保留截图。删除临时诊断提示代码但保留正常授权和回归测试。
**Tech Stack:** Kotlin/Android、Vue/TypeScript、PostgreSQL。
**Spec:** 本对话用户已确认的定点修复设计，及“不能确认的图放在一起”补充。

## 限制
- 不修改QQ adapter及其识别规则，不连接真实手机，不改线上服务/业务数据库，不删除旧APK，不提交Git。
- 所有工作区写入、测试、打包以ko执行，完成核验ko:ko。
- 保留已恢复的generation与顶部裁剪修复；避免全局降低名称可信度。
