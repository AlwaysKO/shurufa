# 同名会话展示分组验收（2026-09-18）

## 行为与边界
- 同一手机、同一App内名称完全相同（去首尾空格）的真实来源统一为一个展示会话，跨日期不拆分。不做近似姓名自动合并。
- 所有待确认占位名称统一为“待确认会话”，不显示随机后缀；包括高置信度和前导空格的历史占位。
- 仅查询时聚合，不物理合并历史来源，不删除图片，不修改Android截图触发或识别规则，无数据库迁移。
- 消息倒序分页、图片前后导航、图片批删均使用user/App/组名范围，不只处理代表ID。
- 多来源组不能用一个代表ID冒充整组合并；每张图的归属操作仍针对其真实来源。整组删除显示来源数，要求用户明确确认全部来源快照；锁内范围变化则409整批拒绝。共享附件引用及跨用户共享文件保留。
- 刷新按App保存组名与ID；代表来源变化或不在首页时精确恢复，不重新插入重复来源标签。
