# 后台同名会话集中展示

**Goal:** 同手机/App同名截图集中到一个展示会话；所有待确认占位名称统一显示待确认会话，不含后缀。
**Architecture:** 保留真实来源，不修改历史数据。新增显式group_names查询范围，同名分组在数据库分页之前完成，单个来源ID不冒充整个分组；读取/图片导航/选中图片删除共享范围。整个同名组删除要求明确来源ID快照及确认，集合变化整批拒绝；合并保留逐真实来源操作。
**Spec:** 用户已确认同手机/App完全同名即统一展示（包括实际不同但同名联系人）；不做相似姓名模糊合并，不改Android截图。
