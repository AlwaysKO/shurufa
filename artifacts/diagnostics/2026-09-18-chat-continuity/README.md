# 聊天连续归属、合并与页面选择记忆（2026-09-18）

## 已实现
- 新迁移022为会话增加合并指向，源行保留为映射、主列表/总数隐藏。人工合并迁移消息归属但不删消息、附件或源资料，不覆盖目标名称。按手机和App隔离，源别名拒绝再次隐式合并；目标别名解析到最终目标、链式指向展平，禁止自合并/循环。后续上报解析映射，与合并串行保护，避免消息落入隐藏源。旧源页面删除拒绝409；明确删除目标才一起清理其映射。
- 新resolve接口支持记住的会话不在列表前100项及被合并后跳转，目标搜索与分页。前端有“合并到…”及自定义Enter/Esc确认；失败保留源选择，不把合并后刷新失败误报为合并失败。
- 按手机分别持久保存最后App及各App会话；切App立即保存（包括加载中刷新），F5/加载恢复选择。恢复接口网络错误不当作删除，明确404才回退。
- Android共有身份稳定器保存已确认精确字形及连续页面内学习到的变体；导航/重启保留已确认映射，临时证据仍隔离。未知首张使用同一次页面内稳定pending key，不逐帧随机分组；可靠确认接续原记录，恢复已有身份时携带严格作用域的临时key，服务端接续归属并防迟到pending复活分组。补传复用首张指纹，不重插原图或重新等待已清理缓存。
- 微信列表点击合并文本（联系人/时间/摘要）可以触发补采；类名空壳不再被当作有可读内容的页面树。列表点击/窗口进入有限检查0/350/900ms，有树时仍由聊天适配器验证。截图失败不落无图占位并有限重试。即时空树截图额外校验标题区，明确列表/设置等非聊天页不保存，没有标题也没有聊天控件证据时只重试，不扩大采集。
