## 显示问题的独立来源

T9Spelling.preedit 的内部对齐为保持分段选字，会返回 ming'tian'78727；RimeEngine 在读音缺失时还会回退 code。它们原本直接作为可见拼音，因此出现数字。

进一步跟踪发现 DecodingInfo.composingStrForCommit 也读取同一 Kernel.wordsShowPinyin，不能直接把“待选拼音”提示塞进引擎缓存，否则回车可能提交提示文案。因此只在 composingStrForDisplay 做显示格式化，保留内部对齐；软/硬键盘回车遇到未解析九宫格时保留组合，不提交残码、不清空按键。该处理不修改词频、个人记忆、分段匹配或候选index。
