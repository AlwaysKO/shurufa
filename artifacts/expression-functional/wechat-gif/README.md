## 新分享路径待验收清单

新代码绕开微信 GIF 的 commitContent，以 `image/gif`、原 URI、EXTRA_STREAM、ClipData、读取授权打开微信分享；需要用户自行选聊天并确认。**打开分享不等于已发送，更不等于接收端验证通过。**

手机可用后：
1. 安装交付APK，确认版本与SHA，不卸载/清数据。
2. 文件传输助手输入谢谢，点首张预制GIF，应出现微信选择聊天，不能再走旧的当前聊天静态图片确认流程。
3. 选择文件传输助手并确认，连续抽帧核对动画；若失败，保留错误与诊断，不算通过。
4. 验证另一张无语/笑死、AI合成GIF、微信静态Emoji、其他应用原commit路径；取消微信分享不应提示“发送成功”。
5. 检查分享打开失败时仅保存原GIF到相册，不偷偷调用静态化的旧路径。
6. 恢复搜狗与关闭常亮。

本轮仅原路径复现与相册对照已真机验证；新路径尚无真机通过证据。
