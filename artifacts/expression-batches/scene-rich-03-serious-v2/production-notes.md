# 你认真的：节奏修正版 v2

用户反馈旧版跳帧太快；本次仅做一款对比样片，不批量替换其余素材。

## 根因与设计

旧版四姿势以1.6秒往返切换，歪头角度较大，情绪停留不足。本版重新生成九宫格：正视→眼珠先侧移→小幅转头→眯眼质疑→逐步回正，不再把原四张简单放慢或倒放，不使用交叉淡化重影。

目标3秒循环，开头约400ms，重点质疑眼神约700ms。身体和背景尽量保持固定，降低大幅姿态变化。母版与提示词留在 assets/expression/batches/scene-rich-03-serious-v2/，布局裁切去除生成九宫格的细白分界，中文仍由确定性字体生成。

## 诚实边界

这仍是AI生成分镜的逐帧GIF，不是视频模型输出，毛发与背景可能有轻微变化；增加中间姿势及表情停顿不等于已获用户流畅度验收。需在 preview.html 看新旧循环对比，而非仅看静态联系表。

旧版保留；新样片不进入正式catalog、server/images根索引或APK。没有手机验证，也不声称修复发送链。

## 本次验证

- 实际成品：240×240、16帧、3000ms、150666字节；原质量审计1/1通过，9实质不同帧、8有效过渡。
- 根代理复跑真实渲染及 build 通过；定向测试5/5。
- 默认全套首次350/351，既有prototypeRenderer文字布局测试5000ms超时；未改超时配置，单worker重跑 `npm test -- --maxWorkers=1` 为351/351通过。不能把首次默认运行写成全绿。
- 规格审查与独立代码质量审查无阻塞。可见风险：质疑后回正有一次较明显位置变化，循环边界也非像素一致；审计通过不是主观流畅度结论。
- 母版来源/提示词/SHA见源manifest；GIF SHA及所有帧延迟见report.json，实际解码抽帧见motion-evidence.png。
