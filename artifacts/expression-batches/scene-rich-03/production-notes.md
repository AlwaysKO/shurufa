# scene-rich-03 生产记录

## 创作方向

本批回应用户要求：提高极简线条互动与犀利搞笑写实动物的比例。只借鉴夸张道具、角色关系、眼神反差等一般表达机制，不复制截图构图、知名角色或真人贴脸。

| 关键词 | 风格与动作 | GIF 字节 |
|---|---|---:|
| 你先跑 | 极简双角色：淡定藏网→举起巨大软捕蝶网→对方回头→高抬腿逃跑 | 69425 |
| 不高兴了 | 极简互动：靠近→戳脸→鼓腮抱臂→跺脚侧目 | 68746 |
| 你认真的 | 原创写实梗犬：盯视→露眼白侧看→歪头瞪眼→眯眼质疑 | 118229 |
| 被你发现了 | 原创写实狸花猫：零食袋边被抓包→收爪侧看→舔嘴→若无其事盯人 | 112654 |

四张均由 image_gen.imagegen 生成四个独立关键姿势。你先跑另经同工具修正为白色背景，未复制参考图中的长刀或贴脸。完整提示词、来源路径、母版 SHA-256 记录于源 manifest；中文由确定性渲染器添加。

## 编码与验证

- 每张 240×240、16 帧、1600ms、无限循环、低于250KB；审计 4/4 通过。
- 四姿势以停顿、往返方式组成16帧，不是16个独立绘制姿势，也不是单图缩放。
- 首帧 WebP fallback，实际 GIF 抽帧见 motion-evidence/；文件 SHA-256、逐帧和尺寸数据见 report.json。
- 命令：`cd server && npx tsx scripts/render-scene-rich-01.ts --batch scene-rich-03`。
- 新批次测试先红后绿；最新完整 `npm test` 为29文件、346/346通过，`npm run build` 通过。既有 Fontconfig 缓存版本警告仍存在。
- 实现后已依次进行规格和独立代码质量审查，实际母版/抽帧另经视觉审查，无阻塞项。
