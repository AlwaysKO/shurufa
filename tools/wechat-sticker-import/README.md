# Windows 微信收藏表情导入助手

本机助手只主动连接指定后台，不开 HTTP 监听端口。当前采集格式在 **Windows 微信 4.1.13.65 / Python 3.12** 验证；其他版本可能报告无法采集，不能保证所有微信版本兼容。不读取聊天记录、不注入或修改微信、不要求管理员权限，也不替用户重启微信。

**本功能尚未部署线上。** 线上生成配对码及一键导入，需要对应后端和页面发布后才能使用。本地测试成功不等于线上已部署。

## 安装与首次配对

1. 安装当前用户的 Python 3.12（带 `py` 启动器），保持电脑微信登录。
2. 下载完整本目录，普通权限 PowerShell 中执行（替换实际地址和目录）：

   ```powershell
   .\install.ps1 -Origin 'https://你的后台域名' -AccountDirectory 'D:\xwechat_files\你的账号目录' -WeixinExe 'D:\微信安装目录\Weixin.exe'
   ```

   地址只能是 HTTPS 根地址，不带用户名、密码、子路径、查询串或片段。仅本机合成数据联调可显式传 `-AllowLocalHttp`，且地址必须是 IP 回环地址，例如 `http://127.0.0.1:3310`；不允许局域网 HTTP。不得关闭 TLS 验证、系统保护或更改执行策略来绕过安装失败。
3. 后台创建一次性配对码；执行：

   ```powershell
   & "$env:LOCALAPPDATA\shurufa-wechat-import\start.ps1" -Pair
   ```

   在隐藏输入提示中粘贴配对码，填写助手名称。不要把配对码或授权写入命令行、脚本、截图或 Git。配对码一次性且过期失效；后台最多保留 20 条助手记录（包括撤销记录），达到上限需管理员处理，不要不断重复配对。
4. 启动助手，然后在后台选此助手点击导入：

   ```powershell
   & "$env:LOCALAPPDATA\shurufa-wechat-import\start.ps1"
   ```

   前台按 **Ctrl+C** 停止。可明确加 `-Background` 打开独立窗口，关闭该窗口停止；不是隐藏服务，不添加开机启动或计划任务。配对不能后台执行。

安装目录为 `%LOCALAPPDATA%\shurufa-wechat-import`，仅当前 Windows 用户权限，包含独立 `venv`、`config.json`、DPAPI 保护的 `token.dpapi`、原图 `cache`。不修改全局 Python。重复安装更新程序但**保留旧配置与授权**；若要换服务器/账号，请停止助手，在本机编辑该目录配置，再重新配对。不要上传或提交该目录；DPAPI 保护绑定当前用户，不能直接复制 token 到另一台电脑。微信数据库密钥仅在内存使用，不保存。

## 导入行为与恢复边界

- 仅执行固定 `wechat_favorites` 任务，本地配置决定账号目录、微信程序与缓存路径；后台不能下发任意命令、SQL、路径或下载地址。
- 收集期间独立线程约每 20 秒续租和心跳；采集结束后向后台提交真实源统计。期间页面可以显示采集中，但不伪造百分比。
- 先按原文件 **SHA-256 完全相同**匹配所有图片，每批至多 500 张；已存在只读取对应关键词，不传图、不改关键词、排序或使用次数。视觉相似、重新编码或压缩后的图片不能保证去重。
- 只上传缺失原图，新增图片暂不分配关键词。后台可将一图关联多个词；不分配时不会进入手机推荐。重复导入只匹配，成功响应丢失时重新查 SHA，不假定失败或重复制造记录。
- 每张原图上限 10 MiB；本机缓存总上限 **512 MiB**。满额会报告失败，不自动删除旧缓存或旧图库；需用户自行确认后整理缓存。GIF 保留动画，不转静态图。本次已知收藏中 3 张 GIF 无法通过严格完整解码，只隔离/报告失败，不上传损坏文件，数量并不是对其他账号的固定假设。
- 单张图片错误不阻断其余图片；已有历史原文件缺失会显示不可用。服务器归档失败会明确提示，已成功入库原图不删除。
- 断网后有限重试与退避；400 不永久重试，429 尊重等待时间。续租失败触发取消本次采集/后续上传，回到领取流程，不持过期租约硬传。离线时后台可再次看到助手离线；保持助手运行并恢复网络后重新领取未过期任务。
- HTTP 响应头与正文均逐段检查总期限及取消（后台单请求 20 秒、CDN 单次 45 秒），到期关闭本次连接，不留下超时网络工作线程；标准 TLS 证书校验保持开启。空闲 socket 取消可能等待当前最多 15 秒读超时。连接/TLS 保留单次 15 秒 socket 限制；操作系统 DNS 解析不保证严格硬截止，不能把它宣传为绝对实时取消。
- 任务租约 90 秒、总有效期 1 小时。任务取消、过期或助手撤销后停止当前任务；撤销返回 401 时停止运行，需重新配对。按 Ctrl+C 停止不会删除缓存，当前任务随后可由后台取消或等待租约超时。
- 若重领后的收藏快照累计数量低于任务已保存统计，停止并提示“收藏快照变化，已停止当前任务，请重新开始导入”，不伪造累计数；已成功图库保留。应在后台新建任务。
- “微信未运行”“密钥未找到”“快照不稳定”都是采集失败，不冒充零收藏成功。日志只显示固定中文提示、固定错误码和数量，不显示授权、微信密钥或 CDN 原图链接。

## 验证

仓库内运行（不读取真实微信的单元测试）：

```powershell
& "$env:LOCALAPPDATA\shurufa-wechat-import\venv\Scripts\python.exe" -m unittest test_collector test_agent test_deadline_http
```

单测使用合成数据和回环假服务。Windows 额外验证当前用户 DPAPI；Linux 会跳过 Windows 专用项。依赖版本在 `requirements.txt` 固定；第三方许可证见 `THIRD_PARTY_NOTICES.md`。真实线上、不同微信版本及用户最终验收另行记录，不以单测通过代替。
